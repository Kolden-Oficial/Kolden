# Narratologia comparada em 3 tradições

> **Atribuição MIT:** sintetizado a partir do material `academic/literature` do repositório
> [`msitarzewski/agency-agents`](https://github.com/msitarzewski/agency-agents) (commit `a597cb6`),
> licença MIT. Reescrito em PT-BR, sem cópia literal, adaptado ao chassi do Liceu (Kolden).

## Princípio

A estrutura narrativa ocidental clássica (3 atos: setup → conflito → resolução) virou **default
invisível** no copy e no storytelling de marca. Para muitos problemas, ela não é a melhor escolha.

Existem pelo menos **3 tradições maduras**, cada uma com lógica própria:

1. **Três atos** (Ocidente, herança aristotélica) — narrativa como **conflito → resolução**.
2. **Kishōtenketsu** (Japão e Leste Asiático) — narrativa em **4 movimentos sem conflito como motor**:
   *Ki* (introdução) / *Shō* (desenvolvimento) / *Ten* (twist / virada inesperada) /
   *Ketsu* (conclusão que reconcilia).
3. **Rasa** (Índia, *Natya Shastra*) — narrativa como **evocação de uma emoção estética (rasa)**,
   não como construção de conflito. As 9 rasas clássicas: erótica, cômica, patética, furiosa,
   heroica, terror, repulsa, maravilha, paz.

Confrontar as 3 antes de decidir evita default ocidental e abre soluções que o conflito linear não
alcança.

## Quando usar

- Storytelling de marca cujo público não responde ao "conflito" ocidental clássico.
- Roteiro de Reels que precisa funcionar **sem antagonista** (kishōtenketsu).
- Copy que precisa **evocar emoção específica** mais do que resolver problema (rasa).
- Diagnóstico de "história morna" — geralmente a tradição escolhida é a errada.
- Conteúdo para público asiático ou indiano (escolher a tradição local em vez de impor o default
  ocidental).

## Passos operacionais

1. **Definir o problema narrativo.** Que história precisa ser contada? Qual a mensagem central?
2. **Esboçar em 3 atos** (Ocidente). Setup (mundo + tensão) → confrontação (conflito crescente) →
   resolução (vitória/derrota). Pergunta: a tensão por conflito existe naturalmente aqui?
3. **Esboçar em kishōtenketsu** (Japão). *Ki* (apresentar elemento A) → *Shō* (desenvolver A sem
   conflito) → *Ten* (introduzir um elemento B aparentemente sem relação) → *Ketsu* (revelar a
   relação entre A e B que reconfigura tudo). Pergunta: a história ganha em surpresa-de-relação
   em vez de em conflito?
4. **Esboçar em rasa** (Índia). Defina **qual rasa** quer evocar (paz? maravilha? cômica?
   patética?). Estruture a peça inteira como uma sequência de gestos, imagens e ritmos que **convergem
   para essa emoção estética** — não para uma resolução de conflito. Pergunta: a história ganha
   em **emoção atmosférica** em vez de em resolução?
5. **Escolher a tradição que melhor serve à mensagem.** Não defaultar. Critério:
   - Mensagem é "como ele superou X"? → 3 atos provavelmente serve.
   - Mensagem é "olha como isso se conecta com aquilo"? → kishōtenketsu.
   - Mensagem é "sinta isto"? → rasa.
   - Mensagem é "essa cultura entende narrativa assim"? → respeite a tradição da cultura.

## Exemplo aplicado

Anúncio meditativo de uma marca de produto bem-estar para classe B:
- Em **3 atos**: mulher cansada → encontra produto → vida muda. Funciona, mas é genérico e ela já
  viu 50 iguais.
- Em **kishōtenketsu**: cena de chá da manhã (Ki) → desenvolve esse momento (Shō) → corta para
  uma cena dela 10 anos antes na correria (Ten) → reconcilia: o chá é o que ela aprendeu a se dar
  (Ketsu). Surpresa-de-relação cria emoção sem antagonista.
- Em **rasa**: a rasa-alvo é *śānta* (paz). Tudo na peça — luz, ritmo, som, micro-gestos — converge
  para evocar paz. Não há "antes e depois". Apenas evocação.

A escolha depende do que a mensagem precisa fazer. Default ocidental teria fechado portas.

## Anti-padrões

- Defaultar para 3 atos sem perguntar se a história tem conflito real (impõe conflito artificial).
- Confundir kishōtenketsu com "3 atos com twist no final" — o *Ten* não é reviravolta do conflito,
  é introdução de um elemento aparentemente sem relação.
- Tratar rasa como "ter sentimento" — rasa é a **emoção estética específica e sustentada** que toda
  a peça evoca, não emoção pontual.
- Aplicar tradição de outra cultura como exotismo (kishōtenketsu por modismo, sem entender) — vira
  apropriação rasa.
- Usar 3 atos para evocar paz — geralmente cria inquietação porque o conflito é incompatível com
  a emoção-alvo.
