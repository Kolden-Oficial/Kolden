# Avaliação de Desempenho e Desenvolvimento

Performance **justa, calibrada e orientada a desenvolvimento**. Avalia-se por evidência, com a mesma
régua para todos — e todo gap vira plano.

## 1. Desenho do ciclo

`Objetivos (início) → acompanhamento (1:1 contínuo) → autoavaliação + avaliação do gestor →
calibração → devolutiva → PDI`. Evite o ciclo anual isolado: o 1:1 contínuo é onde o feedback acontece.

## 2. Rubrica por competência

Para cada competência, defina níveis observáveis (ex.: abaixo / atende / supera) com **comportamento-
âncora** em cada nível. Sem rubrica, a nota vira opinião — e opinião carrega viés.

## 3. Feedback (modelo SBI)

- **Situação** — quando/onde.
- **Comportamento** — o que a pessoa fez (observável, não rótulo).
- **Impacto** — o efeito no time/resultado.

Feedback é sobre comportamento, não sobre a pessoa. Equilibre reforço e desenvolvimento.

## 4. Calibração anti-viés

- Cada gestor pontua **antes** da reunião (reduz ancoragem).
- Compare distribuições entre áreas; questione outliers com evidência.
- Vigie vieses: recência, halo, leniência/severidade, similaridade ("se pareço comigo").
- Decisão de promoção é por competência demonstrada — nunca por tempo de casa ou afinidade.

## 5. Matriz 9-box

Performance (eixo X) × Potencial (eixo Y). Cada quadrante sugere uma ação:
alto/alto → sucessão/stretch; baixo/baixo → plano de recuperação ou saída digna; demais → desenvolvimento
direcionado. É bússola de conversa, não rótulo permanente.

## 6. PDI (plano de desenvolvimento individual)

Para cada gap: **competência-alvo → ação (70/20/10: prática/exposição/formação) → prazo → como medir o
progresso**. O PDI é da pessoa, construído junto, não imposto.

## Vetos
- Sem viés na avaliação/promoção — só competência documentada, mesma régua.
- Avaliações são confidenciais (LGPD) — nunca em texto puro.
- Parecer jurídico sobre desligamento → sinalizar + escalar, sem sentença.
