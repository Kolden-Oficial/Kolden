# Checklist de Qualidade de Saída do Aconselhamento Estratégico

**Checklist ID:** ADVISORY-CL-001
**Referenciado por:** tasks/review.md
**Propósito:** Validar os entregáveis de aconselhamento estratégico quanto à qualidade antes da entrega ao usuário.

[[LLM: INSTRUÇÕES DE INICIALIZAÇÃO

Este checklist valida especificamente a saída de aconselhamento estratégico.

ABORDAGEM DE EXECUÇÃO:
1. Para cada categoria, verifique cada item em relação ao entregável
2. Marque os itens como [x] Aprovado, [ ] Reprovado, [N/A] Não Aplicável
3. Itens CRÍTICOS bloqueiam a entrega; itens não críticos são consultivos

Itens CRÍTICOS são marcados com o sufixo (CRÍTICO).]]

## 1. Análise Multiperspectiva

- [ ] Múltiplas perspectivas ou cenários são considerados, não apenas um caminho (CRÍTICO)
- [ ] Pontos de vista divergentes são representados — não apenas viés de confirmação
- [ ] Efeitos de segunda ordem são explorados (o que acontece depois do primeiro movimento?)
- [ ] Precedentes históricos ou analogias são referenciados onde relevante
- [ ] O impacto sobre os stakeholders é avaliado ao longo das partes afetadas

## 2. Identificação de Risco

- [ ] Os riscos-chave são explicitamente identificados e categorizados (CRÍTICO)
- [ ] A probabilidade e o impacto de cada risco são estimados
- [ ] Estratégias de mitigação ou planos de contingência são propostos
- [ ] O cenário de pior caso é tratado honestamente, não minimizado
- [ ] A irreversibilidade das decisões é sinalizada quando aplicável

## 3. Premissas & Evidências

- [ ] As premissas que fundamentam a recomendação são declaradas explicitamente (CRÍTICO)
- [ ] Evidências ou dados sustentam a análise, não apenas opinião
- [ ] As lacunas de informação são reconhecidas, não encobertas
- [ ] As fontes de incerteza são identificadas
- [ ] O nível de confiança na recomendação é declarado

## 4. Recomendações Acionáveis

- [ ] As recomendações são específicas e acionáveis — não platitudes vagas (CRÍTICO)
- [ ] Próximos passos claros são definidos com responsáveis e prazos
- [ ] Critérios de decisão são fornecidos: como o usuário saberá se isso está funcionando?
- [ ] Gatilhos de prosseguir/não prosseguir ou marcos são identificados
- [ ] Os requisitos de recursos são estimados (tempo, dinheiro, pessoas)

## 5. Coerência Estratégica

- [ ] As recomendações se alinham com os objetivos e restrições declarados
- [ ] Os trade-offs são tornados explícitos — do que você está abrindo mão?
- [ ] As implicações de curto prazo vs longo prazo são distinguidas
- [ ] A dinâmica competitiva é considerada
- [ ] O conselho é calibrado ao estágio e aos recursos do usuário

## 6. Qualidade de Comunicação

- [ ] A análise é estruturada logicamente e fácil de acompanhar
- [ ] O sumário executivo captura a essência em 3-5 frases
- [ ] O jargão é minimizado ou definido
- [ ] A conclusão é definitiva — não "depende" sem resolução

---

## Critérios PASS/FAIL

**PASS (APROVADO):** Todos os itens CRÍTICOS [x] e menos de 3 reprovações não críticas.
**REVISE (REVISAR):** Todos os itens CRÍTICOS [x], mas 3 ou mais reprovações não críticas.
**FAIL (REPROVADO):** Qualquer item CRÍTICO não marcado.
