# Domínios excluídos da análise de concorrentes

Ao analisar a SERP para scoring de concorrente, filtre estes domínios. Não são concorrentes de
negócio reais mesmo quando ranqueiam para a keyword-alvo. Remova-os ANTES de pontuar; se restarem
menos de 3 concorrentes reais, registre o cenário competitivo raso no brief.
