# Dependências do motor de scraping do Argos (camadas verdes).
# Instale com: pip install -r motor/requirements.txt
# A camada `js` (Crawlee) é Node — veja motor/crawlee-node/ (npm install).
#
# As versões são pinadas no momento da vendorização (2026-06-21); o código-fonte de referência
# de cada uma está vendorizado em motor/<repo> (ver _origem.md com os commit SHAs).

scrapling            # engine base: anti-bot, stealth, seletores adaptativos (BSD-3)
scrapy               # crawl em escala, dedup de URL, extração exaustiva de links (BSD-3)
gpt-researcher       # pesquisa LLM multi-retriever + citação + relatório (Apache-2.0)
skyvern              # automação por visão LLM em DOM hostil (AGPL-3.0 — uso interno; ver _origem.md)
apify-client         # cliente oficial da Apify: roda actors gerenciados do Store (camada `apify`)

# Observações:
# - Scrapling e Skyvern usam Playwright; rode `playwright install chromium` após o pip install.
# - GPT-Researcher lê chaves de LLM/retriever do ambiente — resolva via Infisical (/kolden/argos),
#   nunca em texto puro (Constituição Art. VII).
