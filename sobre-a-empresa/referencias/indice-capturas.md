# Índice de Capturas Externas — Kolden
**Atualizado automaticamente pelo workflow de captura.**  
Toda referência processada pelo Hermes é registrada aqui antes de qualquer ação.

---

## Como ler

| Campo | Descrição |
|-------|-----------|
| `data` | Data da captura (YYYY-MM-DD) |
| `fonte` | Rede social ou tipo de conteúdo |
| `autor` | Nome do perfil ou autor |
| `url` | Link original |
| `status` | NOVO / COMPLEMENTA / DUPLICADO |
| `ação` | O que foi feito após aprovação do Ronan |
| `arquivo` | Caminho do arquivo criado/atualizado (se houver) |
