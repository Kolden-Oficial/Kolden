# Atendimento — Processo (Posicionamento → Alinhamento → ClickUp)

⚠️ O que estiver entre **[ ]** são campos que podem ser alterados de acordo com a sua realidade.

⚠️ O nome que acompanhar o ícone 🗎 significa que é um documento necessário para guiar o time na execução do processo.

*   **`Nova demanda: Posicionamento → 60 minutos`**

**O processo**
[ATENDIMENTO] deverá dar um posicionamento para o cliente sobre a nova demanda em até 1 dia útil. Para auxiliar na comunicação utilize o Script de mensagem.

**Explicação**
Esse processo é executado quando uma nova demanda surge (seja ela solicitada pelo cliente ou sugestões desenvolvidas pela agência).
*Ps: Cabe o [ATENDIMENTO] entender a dificuldade da demanda e se caso for necessário solicitar uma call para alinhar as dúvidas.*

**Obrigação**
[ATENDIMENTO] deverá garantir que o cliente seja respondido/posicionado de maneira rápida e eficaz, se colocando à disposição para tirar as todas as dúvidas.
[POSICIONAMENTO] deverá acontecer em até 60 minutos após o surgimento de uma nova demanda.

*   **`Pós posicionamento: Alinhamento → 1 dia`**

**O processo**
[ATENDIMENTO] deverá organizar as tarefas que surgiram (seja em reunião ou por comunicação via grupo de WhatsApp). Depois disso deverá organizar o material recebido (foto, texto, vídeos, referências e etc...) na pasta do cliente que fica localizada no [CLOUD DRIVE] → Cliente.

Após organizar tudo [ATENDIMENTO] deverá solicitar uma call de [ALINHAMENTO] com [GERENTE OPERACIONAL] para explicar todas as tarefas.

**Explicação**
Esse momento é quando o [ATENDIMENTO] alinha todas as demandas que surgiram com [GERENTE OPERACIONAL] para que a mesma possa passar um prazo seguro para execução das tarefas. Depois de definir isso a demanda deverá ser incluída no software de gestão de projetos (Clickup).

**Obrigação**
[GERENTE OPERACIONAL] deverá sair da call de [ALINHAMENTO] com os prazos definidos e os responsáveis por cada tarefa.
[ATENDIMENTO] deverá imediatamente enviar a **[Mensagem 3]** para posicionar o cliente.

*   **`Pós Alinhamento: Clickup → Imediatamente`**

**O processo**
[GERENTE OPERACIONAL] deverá imediatamente lançar todas as tarefas para os responsáveis com seus respectivos prazos no software de gestão (Clickup).

**Explicação**
1. Abrir o **Space** → Anúncios
2. Abrir o **Folder** → Tráfego Pago
    1. Selecionar a visualização em **List**
        1. Criar uma nova **Task** na 1° fase → **Plataforma**
            1. Para lançar uma nova Task lembre-se sempre de usar o padrão de nomeclatura: **[NOME DO CLIENTE] [OBJETIVO DA CAMPANHA] [POSICIONAMENTO] [ASSUNTO]**
        2. Criar um novo cliente no **Custom Field → Clientes**
        3. Marcar o responsável pela **Task**
        4. Preencher o Briefing da **Task**
        5. Preencher o **Start date** e o **Due date**
        6. Preencher o **Custom Field → Orçamento**
        7. Preencher o **Custom Field → Tipo**

`📌` *`Se a`* **`Task`** *`lançada depender de outra`* **`Task`** *`deverá ser adicionada como`* **`Dependency → Tarefa dependente.`**

**Obrigação**
[GERENTE OPERACIONAL] deverá lançar as tarefas imediatamente no Clickup seguindo a explicação acima.
[GERENTE OPERACIONAL] deverá calcular os prazos de entrega com margem de segurança.
