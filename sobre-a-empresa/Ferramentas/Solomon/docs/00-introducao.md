# 00 — Introdução

Fonte: https://docs.solomon.com.br

## O que é a Solomon

A **Solomon** é uma plataforma de analytics e atribuição projetada para ajudar lojas virtuais a entenderem melhor a jornada de compra dos seus clientes e a performance dos seus canais de marketing.

Com a Solomon é possível:

- **Rastrear eventos do site em tempo real** via SDK, capturando cada interação do usuário — da primeira visita à finalização da compra.
- **Enviar pedidos e produtos** via API REST, mantendo os dados sincronizados com a plataforma.
- **Fazer atribuição precisa** de conversões aos canais de marketing que efetivamente geraram resultado.
- **Analisar a jornada completa** do cliente, identificando todos os pontos de contato antes da compra.

## Por que usar

- **Atribuição precisa** — entende qual canal gerou cada venda, mesmo em jornadas complexas com múltiplos pontos de contato.
- **Integração simples** — API REST + SDK JavaScript, com suporte para plataformas próprias e customizadas.
- **Dados em tempo real** — eventos web/mobile e catálogo/pedidos sempre sincronizados.
- **Ambiente de testes** — Sandbox dedicado para desenvolver e validar antes de ir para Live.
