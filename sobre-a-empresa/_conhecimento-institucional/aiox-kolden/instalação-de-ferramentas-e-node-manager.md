# Instalação de Ferramentas e Node Manager

# Tab 1

Excelente! O sistema está te perguntando qual "motor" ele deve usar para instalar e gerenciar os códigos das ferramentas que você acabou de escolher.

A bolinha já está exatamente no lugar certo: **● npm** .

No mundo do desenvolvimento, o npm (Node Package Manager) é o padrão universal. Ele é robusto, seguro e já vem embutido na maioria dos servidores. Não precisamos inventar moda com os outros (pnpm ou bun) no nosso cenário.

##### O que fazer agora:

Apenas aperte **Enter** (mantendo o npm selecionado).

*Nota rápida sobre o texto acima:* Repare que o assistente te mostrou um comando gigante do **Homebrew** (/bin/bash -c "$(curl..."). O Homebrew é uma loja de aplicativos extra para o Linux. **Não se preocupe com ele agora.** Vamos focar em terminar esse assistente primeiro. Se alguma ferramenta que você escolheu precisar do Homebrew no futuro, nós copiamos esse comando e rodamos.

Pode dar o **Enter** no npm com vontade. Acredito que essa seja a última pergunta antes do servidor começar a baixar tudo. Me avise se a "chuva" de instalações começou na sua tela!
