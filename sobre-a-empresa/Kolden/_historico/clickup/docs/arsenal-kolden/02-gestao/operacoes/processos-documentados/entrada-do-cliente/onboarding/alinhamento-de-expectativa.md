# Alinhamento de Expectativas — script de reunião de Onboarding

### Introdução

- [ ] **Apresentação do Onboarding / Alinhamento de expectativas**
*Esse é o nosso primeiro encontro, nesse período de* **15 dias úteis**. *Ainda teremos mais um encontro, um para tratar especificadamente dos detalhes do projeto, que chamamos de kickstart (briefing) e logo após vamos sentar com o time para fazer todo planejamento e desenvolvimento do projeto, setup inicial se necessário.*

### Nossa Cultura
- [ ] Nossa missão é transformar vidas!
- [ ] Nenhuma execução prática acontece antes do Kickstart (briefing inicial)
- [ ] Prezemos pelo planejamento de tudo para que nossa execução seja impecável
- [ ] Somos uma empresa que anota absolutamente tudo
- [ ] Prezamos ao extremo pela organização das informações
- [ ] Sempre enviamos Ata da reunião com os deveres da agência e do cliente
- [ ] Questionamos com o objetivo de buscar o progresso
- [ ] Todas as ideais são discutidas, revisadas e aprovadas internamente antes de serem apresentadas
- [ ] Somos proativos, mas não tomamos a responsabilidade do cliente perante ao projeto (você tem que querer mais que qualquer um aqui dentro)

- [ ] **Apresentação do responsável pelo atendimento diário nos grupos de WhatsApp**
*X será o responsável pelo atendimento diário no grupo de WhatsApp, toda solicitação, dúvidas poderão ser tratas nesse canal de comunicação rápida.* **Vale frisar que: não tratamos uma demanda que foi solicitada de maneira imediata. A não ser em uma eventualidade ou urgência.**

- [ ] **Explicação sobre como funciona o tráfego pago**
- [ ] **Explicar os pontos do contrato**
- [ ] **Vencimento do contrato**
- [ ] **Atraso no pagamento**
- [ ] **Responsável pelo financeiro**
- [ ] **Responsável atendimento técnico**

- [ ] **Explicar o cronograma futuro (resumo do kickoff)**
- [ ] Onboarding → Apresentação e alinhamento expectativas
- [ ] Kickstart → Briefing inicial do projeto (em até 3 dias após o onboarding)
- [ ] Moodboard → Reunião interna com a equipe (em até 3 dias após o briefing)
- [ ] Estratégia & Setup → Elaboração do plano tático e início dos primeiros entregáveis
- [ ] Ativação → Momento de ativar as campanhas e começar a rodar o tráfego

### Finalização
- [ ] Abrir para perguntas do Cliente e conferir se ele entendeu tudo
- [ ] Para encerrar, precisamos deixar agendado a nossa reunião de briefing inicial
- [ ] Enviar convite no Google Agenda
- [ ] Avisar sobre o envio resumido do cronograma
- [ ] Avisar sobre o envio da ata de reunião e caso tenham alguma dúvida poderão entrar em contato via WhatsApp
