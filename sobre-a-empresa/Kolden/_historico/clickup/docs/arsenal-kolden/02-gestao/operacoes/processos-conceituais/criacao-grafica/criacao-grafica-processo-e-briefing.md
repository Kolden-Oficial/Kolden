# Criação Gráfica — Processo + Documento de Briefing

## Processo de Criação Gráfica (page_id: 8cdvxek-4543)

### Introdução
*Todo o processo foi documentado e criado baseado em nosso software de gestão, o ClickUp.*
*Esse processo é realizado assim que o cliente solicita ou a agência sugere a criação de uma arte avulsa. Em casos de posts ou criativos, seguimos o processo de social media ou tráfego pago.*

*   **`Quando a demanda surgir: Briefing → 1 dia útil`**

Após o surgimento da demanda, o [ATENDIMENTO] deverá marcar uma reunião de briefing (se a demanda for muito simples pode apenas pegar informações pelo WhatsApp) com o cliente para entender exatamente o que o cliente pediu ou se for demanda sugerida pela agência, explicar pro cliente, o que nós pensamos.

Na reunião de briefing deve se preencher todo o documento, com o maior número detalhes possíveis da demanda — formato, tamanho, referências etc, e **principalmente, definir prazo final para a entrega junto com o cliente.**

O responsável pela reunião de briefing é o [ATENDIMENTO], se caso o [DESIGNER] quiser participar é opção dele.
O documento da reunião de briefing precisa ser preenchido por completo e enviado para o cliente, juntamente com o prazo final bem definido e de forma clara.

*   **`Após Briefing: Alinhamento Interno → 1 dia útil`**

[ATENDIMENTO] deverá solicitar uma call de alinhamento com [GERENTE OPERACIONAL] para explicar essa nova demanda. [GERENTE OPERACIONAL] deverá sair da call de alinhamento com os prazos definidos e os responsáveis por cada tarefa. [ATENDIMENTO] deverá imediatamente enviar uma mensagem posicionando o cliente.

*   **`Após Alinhamento Interno: Criar Task → Imediatamente`**

[GERENTE OPERACIONAL] deverá imediatamente lançar todas as tarefas no ClickUp:
1. Space → Operacional → Folder → Criação gráfica → List
2. Criar Task na 1° fase → Design
3. Padrão de nomenclatura: **[NOME DO CLIENTE] [FORMATO] [ASSUNTO]**
4. Custom Field → Clientes (criar novo cliente)
5. Marcar responsável, preencher Briefing, Start date, Due date, Custom Field → Tipo

*   **`Após Criar Task: Criação → 3 dias úteis`**

[DESIGNER] vai abrir a tarefa, analisar o documento de briefing, ler todas as informações, procurar mais referências, e vai iniciar um esboço da demanda.

**Etapas da criação:**
*   **Criação** — fase em que a arte é criada de fato (responsável: designer).
*   **Direção de arte** — análise de layout para verificar se segue identidade visual do cliente (responsável: diretor de arte).
*   **Revisão** — revisão geral de arte e copy (responsável: atendimento).
*   **Alteração** — quando arte ou copy precisa de alteração, solicitada pelo atendimento, diretor de arte ou cliente.

Obs: Assim que o designer tiver em mãos um esboço apresentável, é interessante o [ATENDIMENTO] mostrar esse esboço pro cliente, para ele dar um posicionamento se a linha que o [DESIGNER] seguiu está ok e se pode dar continuidade. Também conta uma micro entrega (overdelivery).

*   **`Após Criação: Aprovação → 1 dia útil`**

[ATENDIMENTO] vai enviar a demanda pro cliente aprovar. Se caso houver alguma alteração, [ATENDIMENTO] deverá colocar diretamente nos comentários da tarefa no ClickUp, marcando o responsável. Em caso de alteração que passe do prazo final estipulado, o [ATENDIMENTO] deverá posicionar o cliente claramente sobre o novo prazo.
