# QUESTIONÁRIO DE NEGÓCIO & PERFORMANCE (360°)

# Tab 1

### **QNP UNIVERSAL – QUESTIONÁRIO DE NEGÓCIO E PERFORMANCE (360°)**

Este Questionário de Negócio e Performance (QNP) foi desenhado como um **template universal** , aplicável a qualquer nicho (serviços, e-commerce, SaaS, infoprodutos, negócios locais ou B2B).

O objetivo é simples e ambicioso: **entender 100% do negócio** , do ponto de vista estratégico, financeiro, comercial, operacional e de marketing, criando base sólida para diagnóstico, plano de ação e tomada de decisão.

Preencha com o máximo de clareza e honestidade possível. Não existem respostas certas — existem respostas úteis.

#### **1. CONTEXTO DO NEGÓCIO**

**1.1 Nome da empresa / projeto** *Exemplo:* Clínica Alpha / Loja XYZ / Projeto João Consultoria

**1.2 Segmento / nicho de atuação** Descreva de forma objetiva o mercado em que você atua. *Exemplo:* Clínica odontológica, e-commerce de suplementos, consultoria B2B.

**1.3 Modelo de negócio** Como o dinheiro entra hoje?( ) Serviço( ) Produto físico( ) Produto digital( ) Assinatura / recorrência( ) Misto

**1.4 Estrutura atual do negócio** Quantas pessoas estão envolvidas diretamente na operação e vendas? *Exemplo:* 1 dono + 2 vendedores + 1 gestor de tráfego.

#### **2. MOMENTO ATUAL DA EMPRESA**

**2.1 Como você define o momento atual do negócio?** ( ) Estagnado( ) Crescimento lento( ) Crescimento acelerado( ) Em queda

*Exemplo:* Crescimento, porém sem previsibilidade.

**2.2 Principal prioridade hoje** O que mais precisa melhorar agora? *Exemplo:* Aumentar volume de leads qualificados / melhorar conversão / escalar faturamento.

#### **3. FINANCEIRO E MÉTRICAS-CHAVE**

**3.1 Faturamento médio mensal atual** Valor médio dos últimos 3 meses. *Exemplo:* R$ 80.000/mês.

**3.2 Faturamento mensal desejado (recorrente)** Valor que faria o negócio operar em um cenário ideal. *Exemplo:* R$ 200.000/mês.

**3.3 Em quanto tempo você gostaria de atingir esse faturamento?** ( ) 90 dias( ) 6 meses( ) 12 meses( ) Não sabe

**3.4 Margem de contribuição média (%)** Venda – custos variáveis (impostos, comissões, taxas, frete, etc). *Exemplo:* 35%.

#### **4. OFERTA E PRODUTOS**

**4.1 Principal produto ou serviço hoje** Qual é o carro-chefe do negócio? *Exemplo:* Consulta + pacote de tratamento / Curso online / Plano mensal.

**4.2 Ticket médio atual** Valor médio por venda. *Exemplo:* R$ 1.500.

**4.3 Existem upsells, cross-sells ou recorrência?** Se sim, descreva. *Exemplo:* Manutenção mensal, garantia estendida, mentoria.

#### **5. MARKETING E AQUISIÇÃO**

**5.1 Hoje você investe em tráfego pago?** ( ) Sim( ) Não

**5.2 Se sim, quanto investe por mês em média?** *Exemplo:* R$ 5.000/mês.

**5.3 Canais utilizados atualmente** ( ) Instagram / Facebook Ads( ) Google Ads (Search, Display, YouTube)( ) TikTok Ads( ) Orgânico (conteúdo)( ) Indicações( ) Outros

**5.4 Quando investe em marketing, o faturamento:** ( ) Cresce de forma previsível( ) Cresce, mas oscila( ) Não muda muito( ) Não gera resultado

#### **6. FUNIL DE VENDAS E CONVERSÃO**

**6.1 Como funciona hoje o funil de vendas?** Descreva o caminho do cliente, do primeiro contato até a venda. *Exemplo:* Anúncio → WhatsApp → atendimento → fechamento.

**6.2 Seu funil hoje é mais focado em:** ( ) Venda direta( ) Agendamento / diagnóstico( ) Conteúdo + nutrição( ) Misto

**6.3 Você acompanha métricas como:** CPL, CPA, taxa de conversão, CAC, LTV?( ) Sim( ) Parcialmente( ) Não

#### **7. PÚBLICO E MERCADO**

**7.1 Quem é o cliente ideal (ICP)?** Descreva o perfil com o máximo de detalhe possível. *Exemplo:* Homens, 30–45 anos, renda acima de R$ 6k, empresários.

**7.2 Quais são as principais dores desse público?** *Exemplo:* Falta de previsibilidade financeira, pouco tempo, medo de errar.

**7.3 Quais são as principais objeções antes da compra?** *Exemplo:* Preço, confiança, timing.

#### **8. POSICIONAMENTO E DIFERENCIAÇÃO**

**8.1 O que faz seu negócio ser diferente dos concorrentes?** (Proposta Única de Valor – PUV) *Exemplo:* Atendimento premium + garantia + método exclusivo.

**8.2 Principais concorrentes ou referências de mercado** *Exemplo:* Empresa X, Perfil Y, Marca Z.

#### **9. HISTÓRICO E APRENDIZADOS**

**9.1 O que já foi testado e funcionou bem no passado?** *Exemplo:* Promoções sazonais, indicação, campanhas locais.

**9.2 O que já foi testado e não funcionou?** *Exemplo:* Anúncios genéricos, descontos agressivos.

#### **10. OBSTÁCULOS E DORES-CHAVE**

**10.1 Hoje, o que mais trava o crescimento do negócio?** *Exemplo:* Falta de volume, tráfego caro, baixa conversão, time.

**10.2 Se esse problema fosse resolvido, o que mudaria no seu negócio e na sua vida?** Pergunta estratégica para entender impacto emocional e financeiro.

#### **11. INVESTIMENTO E EXPECTATIVA**

**11.1 Quanto você estaria disposto a investir mensalmente para crescer com previsibilidade?** ( ) Até R$ 5.000( ) R$ 10.000 – R$ 30.000( ) Acima de R$ 50.000( ) Depende do plano

**11.2 O que você espera de um parceiro estratégico nesse processo?** *Exemplo:* Clareza, previsibilidade, crescimento sustentável.

#### **12. EXPECTATIVA DE PARCERIA (PERGUNTA ESTRATÉGICA)**

**12.1 Qual tipo de parceiro você está buscando neste momento?** Essa pergunta é essencial para alinhar expectativa, profundidade do trabalho e modelo de crescimento.

( ) **Uma agência de marketing digital tradicional** Voltada principalmente para execução operacional: anúncios, criativos, posts e presença digital. Normalmente trabalha com escopo fechado, menor envolvimento estratégico e pouca profundidade em dados, funil e vendas. *Exemplo:* Preciso rodar anúncios e melhorar minha presença online, sem mexer muito na estrutura do negócio.

( ) **Uma Gestão Empresarial Executiva orientada à performance (modelo parceiro / sócios estratégicos)** Atuação profunda e integrada, com foco total em funis de vendas, conversão, marketing, comercial, métricas, processos e tomada de decisão. O objetivo é crescimento previsível, escala e aumento real de faturamento. Costuma exigir maior investimento, porém com foco direto em retorno e performance. *Exemplo:* Quero alguém que pense o negócio comigo, mexa em oferta, funil, vendas e marketing para escalar resultado.

#### **13. OBJETIVO FINAL**

**13.1 Se este projeto fosse um sucesso absoluto, como estaria seu negócio em 12 meses?** Descreva faturamento, estrutura, rotina, time, nível de previsibilidade e qualidade de vida desejada.

##### **FIM DO QNP**

Este documento é a base para diagnóstico, estratégia e plano de crescimento. Quanto mais claro você for aqui, mais preciso, direto e eficaz será o plano construído a partir dele.
