# Tab 1

Excelente! O cérebro voltou para o modo automático (model set to openrouter/auto).

Eu sei que você está olhando para esse connected | error na tela e pensando: *"Poxa, eu paguei e ainda tá dando erro?"* .

Pode ficar tranquilo! Esse "error" vermelho aí embaixo é só um "fantasma". O OpenClaw é um sistema contínuo, então ele está simplesmente te lembrando que **a última tentativa** (antes de você colocar os créditos) falhou. Ele não sabe que você abasteceu a conta até você tentar falar com ele de novo!

##### O Empurrão Final:

Para o OpenClaw ir lá na OpenRouter e ver que a carteira agora está cheia, você precisa forçar uma nova interação.

Aí mesmo na linha de comando do chat, digite:Oi, acordou?

Aperte **Enter** .

Ao fazer isso, o sistema vai disparar uma requisição nova. Se o seu cartão já foi processado pela OpenRouter (o que costuma levar de 1 a 2 minutinhos), a luzinha do error vai sumir e ele vai te responder um belo "Olá!".

Manda a mensagem e me diz o que ele respondeu! Se por acaso o erro de "billing" persistir, é só a gente dar 2 minutos para o servidor do site deles atualizar o seu saldo, mas 99% das vezes é instantâneo. Vai lá! 🚀
