# Configuração do OpenClaw: Chave API

# Tab 1

**Não, de jeito nenhum!** Pode ficar super tranquilo.

Como um bom sistema de arquitetura, o OpenClaw já salvou a sua chave do OpenRouter a sete chaves no arquivo de configuração dele (o openclaw.json) lá na Fase 1. Ele tem uma memória excelente para essas coisas.

Quando o assistente passar pela tela perguntando sobre Provedores de IA ou API Keys, ele provavelmente vai mostrar a sua chave escondida (algo como \*\*\*\*) ou apenas perguntar se você quer configurar.

##### Como agir no terminal agora:

**Se ele perguntar de provedor/chave:** Apenas aperte **Enter** para pular ou manter o que já está lá. Não digite nada de novo para não sobrescrever a chave que já está funcionando com os seus créditos!

**Se ele perguntar do Telegram:** Aperte Enter (ele já sabe que é o @AioxKolden\_BOT).

**Se ele perguntar do DuckDuckGo:** Aperte Enter.

Siga dando **Enter** com confiança em tudo que aparecer, até você dar de cara com a nossa grande meta de hoje:

◆ Configure skills now? (recommended)

Aí sim, nessa você muda para **● Yes** e deixa o download das ferramentas pesadas começar.

Vá em frente, dê os Enters (sem digitar a chave) e me avise se o arsenal começou a ser baixado!
