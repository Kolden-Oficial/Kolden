# Install missing skill dependencies

# Tab 1

Aí está o Arsenal de Elite! Essa é a lista completa das ferramentas (Skills) que o seu Agente pode aprender a usar.

Em vez de marcarmos "Skip for now" como na primeira vez, agora nós vamos armá-lo.

Como Arquiteto, nós não vamos instalar lixo inútil no servidor (como controle de luzes Philips Hue ou caixas de som Sonos, a menos que você queira brincar com isso depois). Nós vamos instalar o que importa para uma operação corporativa autônoma.

##### O que selecionar (O pacote corporativo):

Use as setinhas para cima/baixo para navegar. Para **marcar** um item, você aperta a **Barra de Espaço** (um "X" vai aparecer no quadradinho).

**Marque com a barra de espaço exatamente estas 4 ferramentas vitais:**

◻ 📄 nano-pdf *(Isso vai dar a ele o poder de ler e extrair textos de PDFs reais).*

◻ 📜 session-logs *(Isso é a base para a Memória dele funcionar e ele lembrar do que vocês conversaram ontem).*

◻ 🧾 summarize *(Isso permite que ele resuma textos e links gigantes que você mandar para ele).*

◻ 🐦 xurl *(Isso dá a ele a habilidade de acessar URLs/links de sites normais que você jogar no chat).*

*(Opcional: Se você usa o GitHub para código, pode marcar o github. Se usa o Trello, marque o trello. Mas as 4 acima são as essenciais de hoje).*

##### O Checkpoint da Fase 2:

Depois de marcar o X nas opções acima usando a barra de espaço, aperte **Enter** .

Ele vai começar a baixar e instalar tudo no seu Linux. Como estamos instalando ferramentas de extração de PDF e manipulação de rede, o terminal pode ficar bem agitado por uns minutos.

Aperte o Enter e me avise quando ele terminar de instalar e te devolver o controle do painel! 🚀
