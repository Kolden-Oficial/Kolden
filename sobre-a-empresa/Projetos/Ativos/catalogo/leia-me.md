# CataLogo — Tracker Flow

> Plataforma de **atribuição e rastreamento de conversões**: cliques, leads e conversões com sincronização S2S (Meta CAPI, TikTok Events API, GoHighLevel, GA4).

## Cliente

Dossiê (negócio, contrato, ICP, metas): [`clientes/ativos/catalogo.md`](../../sobre-a-empresa/clientes/ativos/catalogo.md). Este projeto é a **execução**; o dossiê é a **inteligência de negócio**.

## O que é

Aplicação fullstack **React 18 + TypeScript + Vite** com backend **Supabase** (PostgreSQL, Auth, RLS, Edge Functions em Deno). Permite criar links UTM rastreados, capturar leads em landing pages A/B, receber webhooks de redes de afiliados e sincronizar eventos para plataformas de marketing.
