# Recorte — Projetos fechados (Job) vs. Unitários (SF/LF/Each)

> **Fonte:** `dados/planilha-vilela.json`.
> **Corte:** agrupamento por coluna `Unit`. A leitura "preço médio" só faz sentido dentro de cada unit (comparar $/SF de tape com $/Job de kitchen é enganoso).

## Legenda das unidades

| Unit    | Significado                                             |
|---------|---------------------------------------------------------|
| SF      | Square Foot — preço por pé quadrado                     |
| LF      | Linear Foot — preço por pé linear                       |
| Each    | Por peça / unidade instalada                            |
| Job     | Projeto fechado, escopo definido em `Description`       |
| Step    | Por degrau                                              |
| Percent | Percentual do subtotal (aplicado sobre outros itens)    |
| Door    | Por porta                                               |
| Patch   | Por remendo isolado                                     |

## Leitura

- **Job (19 serviços):** projetos fechados, alto ticket ($500 a $65k). Concentração em Kitchens, Bathrooms, Roofing repair, Basement finish. **Aqui é a venda consultiva** — CRM, proposta, prova social.
- **SF (44 serviços):** por área. **Aqui a calculadora pública funciona** — o prospect entende $/SF, o cliente ganha lead qualificado.
- **LF (18 serviços):** por comprimento. Trim, base, deck railing, siding transitions. Também elegível para calculadora.
- **Each (25 serviços):** peça por peça. Bom para "add-on shopping" no bottom-of-funnel (smart switch, motion sensor, storm door).
- **Percent (2 serviços):** overhead sobre subtotal. Não é serviço vendido isolado.
