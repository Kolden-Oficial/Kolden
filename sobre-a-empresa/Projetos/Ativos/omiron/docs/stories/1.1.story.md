# Story 1.1 — Setup do Projeto

**Epic:** E1 — Fundação & Autenticação
**Status:** InReview

**Quality Gate Tools:** [typecheck, lint, build]

## Story

Como desenvolvedor, quero ter o monorepo Next.js configurado com TypeScript, Tailwind CSS, shadcn/ui e tRPC, para que todos os epics posteriores possam ser desenvolvidos na stack correta desde o início.

---

## Acceptance Criteria

1. `npm run dev` inicia a aplicação em `localhost:3000` sem erros
2. TypeScript configurado com `strict: true` e sem erros de tipo
3. Tailwind CSS funcionando com o arquivo de configuração customizado
4. shadcn/ui inicializado e ao menos um componente (Button) renderizado corretamente
5. tRPC configurado com um router base contendo endpoint `health.check` que retorna `{ status: "ok" }`
6. ESLint configurado com regras TypeScript e passando sem warnings
7. `npm run build` gera build de produção sem erros
8. `npm run typecheck` passa sem erros
9. Estrutura de diretórios segue o padrão definido em Dev Notes

---

## Dev Notes

### Stack de referência

```
Next.js 14 (App Router) + TypeScript + Tailwind CSS + shadcn/ui + tRPC + Prisma + Supabase
```

### Estrutura de diretórios alvo

```
src/
├── app/
│   ├── (patient)/          # Rotas do paciente
│   ├── (admin)/            # Rotas da secretária
│   ├── (medico)/           # Rotas do médico
│   ├── api/
│   │   └── trpc/
│   │       └── [trpc]/
│   │           └── route.ts
│   ├── layout.tsx
│   └── page.tsx
├── components/
│   └── ui/                 # shadcn/ui components
├── server/
│   ├── routers/
│   │   ├── health.ts
│   │   └── index.ts
│   └── trpc.ts
├── lib/
│   └── trpc/
│       ├── client.ts
│       └── provider.tsx
└── types/
```

### tRPC setup pattern

```typescript
// src/server/trpc.ts
import { initTRPC } from '@trpc/server'

const t = initTRPC.create()
export const router = t.router
export const publicProcedure = t.procedure
```

### Versões alvos

- next: 14.x
- @trpc/server: 11.x
- @tanstack/react-query: 5.x
- typescript: 5.x
