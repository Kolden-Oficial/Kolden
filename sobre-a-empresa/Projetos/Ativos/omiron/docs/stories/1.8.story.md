# Story 1.8 — Onboarding Inicial

## Story

Como novo paciente, quero completar um fluxo de onboarding guiado após meu primeiro login, para que o app seja configurado corretamente para o meu diagnóstico e eu comece a usar o Omiron sem confusão.

---

## Acceptance Criteria

1. Onboarding é ativado automaticamente no primeiro login (flag `force_password_change` = true OR ausência de `diagnoses` no perfil)
2. Passo 1: Boas-vindas — tela com animação da planta-semente e explicação do Omiron em 3 frases
3. Passo 2: Seleção de diagnóstico — paciente seleciona seu(s) diagnóstico(s) principal(is) de uma lista pré-definida
4. Passo 3: Configuração de lembrete — paciente define horário preferido para o lembrete diário (campo de hora)
5. Passo 4: Conclusão — animação de "planta plantada", texto motivador e botão para ir ao dashboard
6. Progresso do onboarding salvo no servidor (paciente pode retomar se fechar o app antes de terminar)
7. Onboarding pode ser pulado após o Passo 1 com confirmação ("Pular para depois")
8. Onboarding não aparece novamente após conclusão
9. Se paciente pular, pode reiniciar via `/dashboard/configuracoes`

---

## Scope

### IN
- Fluxo de onboarding em 4 passos (stepper)
- Seleção de diagnósticos
- Configuração de horário de lembrete
- Salvar progresso no servidor
- Animação da planta-semente (CSS/Lottie simples)

### OUT
- Onboarding médico/secretária (não precisam de onboarding)
- Tutorial interativo com tooltips (Story 4.6)
- Conteúdo personalizado por diagnóstico (Story 5.5 — depende de conteúdo do Dr. Ariosto)

---

## Dependencies

- Story 1.4 (autenticação — saber que é o primeiro login)
- Story 1.2 (tabela `patient_profiles` com campo `diagnoses` + notifications com horário de lembrete)

### Animação da planta-semente

Opção simples com CSS animations (sem dependência externa):

```css
@keyframes grow {
  from { transform: scale(0) translateY(20px); opacity: 0; }
  to   { transform: scale(1) translateY(0);    opacity: 1; }
}

.plant-animation {
  animation: grow 1.2s ease-out forwards;
}
```

Usar emoji 🌱 ou SVG simples enquanto ilustração definitiva não está disponível.
