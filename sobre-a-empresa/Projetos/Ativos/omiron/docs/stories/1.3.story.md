# Story 1.3 — Deploy Vercel

## Story

Como desenvolvedor, quero ter o app deployado na Vercel Pro com domínio configurado e deploy automático a cada push, para que o ambiente de produção esteja disponível desde o início e todos os epics possam ser validados em produção continuamente.

---

## Acceptance Criteria

1. App deployado em Vercel Pro e acessível via URL pública
2. Deploy automático configurado para branch `main` (produção)
3. Preview deployments gerados automaticamente para cada Pull Request
4. Domínio customizado configurado com HTTPS (certificado SSL automático da Vercel)
5. Todas as variáveis de ambiente de produção configuradas no painel da Vercel (sem hardcode)
6. Deploy de produção passa sem erros de build
7. Health check endpoint (`/api/trpc/health.check`) responde `200 OK` em produção

## Dev Notes

### Configuração Vercel recomendada

```
Framework Preset: Next.js
Build Command: npm run build
Output Directory: .next
Install Command: npm install
Node.js Version: 20.x
```

### Environments na Vercel

| Environment | Branch | Uso |
|-------------|--------|-----|
| Production | `main` | Produção real |
| Preview | PRs e branches | Testes de feature |

### Variáveis por environment

Algumas variáveis devem ser diferentes em Preview vs. Production:
- `DATABASE_URL` → banco de dev vs. banco de prod
- `NEXT_PUBLIC_SUPABASE_URL` → projeto Supabase de dev vs. prod

### Estrutura de branches sugerida

```
main           → produção (Vercel Production)
feat/*         → features (Vercel Preview)
fix/*          → correções (Vercel Preview)
```
