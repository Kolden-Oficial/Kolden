## Story

Como Dr. Ariosto, quero criar e editar a ficha completa de um paciente (foto, diagnóstico, medicação, metas e observações), para que eu tenha todas as informações clínicas centralizadas e acessíveis a qualquer momento.

---

## Acceptance Criteria

1. Dr. Ariosto consegue criar uma ficha de paciente com: nome, foto, diagnóstico(s), medicação prescrita, metas terapêuticas e observações médicas
2. Upload de foto do paciente funciona (armazenado no Supabase Storage bucket `photos`) e exibe preview imediato
3. Paciente vê sua própria ficha em modo leitura — não consegue editar diagnóstico ou medicação
4. Secretária vê apenas: nome, foto, email e telefone (dados não clínicos)
5. Dr. Ariosto consegue editar qualquer campo da ficha
6. Validação de campos: nome obrigatório, foto opcional, pelo menos 1 diagnóstico obrigatório
7. Mensagem de erro clara quando upload da foto falha
8. Ficha carrega em menos de 2 segundos (sem foto acima de 5MB)
9. Ficha exibe data de criação e última atualização

### Upload de foto

```typescript
// src/lib/supabase/storage.ts
import { createClient } from './client'

export async function uploadPatientPhoto(file: File, userId: string): Promise<string> {
  const supabase = createClient()
  const path = `patients/${userId}/${Date.now()}-${file.name}`

  const { error } = await supabase.storage
    .from('photos')
    .upload(path, file, { upsert: true })

  if (error) throw error

  const { data } = supabase.storage.from('photos').getPublicUrl(path)
  return data.publicUrl
}
```
