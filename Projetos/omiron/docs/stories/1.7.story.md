## Story

Como produto, quero ter o design system Omiron configurado no Tailwind e shadcn/ui com a paleta, tipografia e componentes base corretos, para que todas as telas do app tenham identidade visual consistente e sofisticada desde o início.

---

## Acceptance Criteria

1. Paleta Omiron configurada no `tailwind.config.ts` como tokens CSS customizados:
   - `omiron-navy`: #1a1040 (fundo escuro principal)
   - `omiron-wine`: #2d0f2d (tom vinho/roxo escuro)
   - `omiron-gold`: #c9922a (dourado âmbar — destaque)
   - `omiron-ivory`: #f5f0e8 (branco marfim — texto claro)
   - `omiron-muted`: #8a7e9a (texto secundário)
2. Tipografia configurada: heading em serif (Playfair Display), body em sans-serif (Inter)
3. Componentes shadcn/ui reestilizados com a paleta Omiron:
   - Button (variantes: primary, secondary, ghost)
   - Card
   - Input, Textarea
   - Badge
   - Dialog/Modal
   - Separator
4. Página de showcase de componentes acessível em `/design` (apenas em desenvolvimento)
5. Dark mode como padrão (paleta navy como base)
6. Contraste de texto adequado — WCAG AA mínimo (4.5:1 para texto normal)

## Dev Notes

### Configuração de cores no Tailwind

```typescript
// tailwind.config.ts
import type { Config } from 'tailwindcss'

const config: Config = {
  darkMode: 'class',
  content: ['./src/**/*.{ts,tsx}'],
  theme: {
    extend: {
      colors: {
        omiron: {
          navy: '#1a1040',
          wine: '#2d0f2d',
          gold: '#c9922a',
          ivory: '#f5f0e8',
          muted: '#8a7e9a',
          surface: '#231545', // cards sobre navy
          border: '#3d2060',  // bordas sutis
        },
      },
      fontFamily: {
        heading: ['var(--font-playfair)', 'Georgia', 'serif'],
        body: ['var(--font-inter)', 'system-ui', 'sans-serif'],
      },
    },
  },
}
```

### globals.css — dark mode como default

```css
:root {
  --background: 26 16 64;   /* omiron-navy */
  --foreground: 245 240 232; /* omiron-ivory */
  --card: 35 21 69;          /* omiron-surface */
  --primary: 201 146 42;     /* omiron-gold */
  --primary-foreground: 26 16 64;
  --muted: 61 32 96;         /* omiron-border */
  --muted-foreground: 138 126 154; /* omiron-muted */
  --border: 61 32 96;
  --ring: 201 146 42;
}
```

### Variantes do Button

| Variante | Background | Text | Use case |
