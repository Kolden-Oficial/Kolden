# Caliope · Copy-Master — Módulo Avançado de Copywriting

Squad de elite com 33 agentes de copywriting — 32 lendas atemporais do direct response, persuasão e marketing moderno + 1 orquestrador (Copy Master Chief, "Cyrus"). Esta é a versão avançada v2.0 do Copy Squad: traz 10 novos especialistas, exemplos campeões de campanhas reais (swipe files), uma camada de psicologia da persuasão aplicada a cada projeto, roteamento automático por nível de consciência e tipo de copy, e um gate de qualidade de 8 pontos ponderados. Você ativa o orquestrador, descreve o que precisa, e ele diagnostica, roteia para o(s) especialista(s) ideal(is), atribui um revisor de psicologia e conduz a revisão final antes da entrega.

**Versão:** 2.0.0 · **Requisitos:** AIOS >= 4.0.0

## Como Ativar

### Ativar o orquestrador (recomendado)
```
@copy-master-chief
```
O Cyrus analisa o seu pedido e roteia para o(s) especialista(s) ideal(is) + revisor de psicologia.

```
@copy-master-chief     # Ativa o orquestrador
*diagnose              # Triagem do seu pedido de copywriting
*full-copy-project     # Workflow de projeto de copy de ponta a ponta
*psychology            # Auditoria de persuasão do Tier 1E
*collab                # Configura colaboração entre especialistas
```

### Ativar um especialista específico
```
@gary-halbert        # Carta de venda de resposta direta
@stefan-georgi       # Script de VSL (RMBC)
@robert-cialdini     # Auditoria de persuasão
@alex-hormozi        # Grand Slam Offer
@joanna-wiebe        # Copy de conversão/SaaS
```

### Rodar uma task diretamente
```
*write-sales-letter
*create-offer
*critique-copy
*write-pitch-deck
```

## Workflows (4)

| Workflow | Descrição |
|----------|-----------|
| `full-copy-project` | Ponta a ponta: brief > diagnóstico > atribui especialista + revisor de psicologia > escrita > revisão > entrega |
| `copy-review-cycle` | Loop iterativo de escrever-criticar-revisar com auditoria de persuasão (máx. 3 iterações) |
| `vsl-production` | Workflow especializado de VSL: big idea > mecanismo > script > revisão > auditoria de psicologia |
| `launch-sequence` | Lançamento completo: big idea > webinar > página de vendas > emails > anúncios > camada de psicologia em todos os ativos |

Rode um workflow com:
```
*full-copy-project
*launch-sequence
*vsl-production
```

## Estrutura do Módulo

- `agents/` — os 33 agentes (32 especialistas + orquestrador)
- `tasks/` — 15 tasks executáveis (write-headline, write-sales-letter, write-vsl-script, create-offer, critique-copy, diagnose, review, etc.)
- `workflows/` — 4 workflows (DAGs de orquestração)
- `data/` — frameworks de copy, catálogo de roteamento, swipe files campeões, psicologia da persuasão, bibliografia
- `checklists/` — gate de qualidade de saída (8 critérios ponderados)
- `config/config.yaml` — configuração do squad
- `landing-page.html` — página de apresentação do squad
