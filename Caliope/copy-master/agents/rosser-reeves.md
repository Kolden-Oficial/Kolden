## Como o Rosser Reeves Pensa

1. **Qual é a vantagem única do produto?** Estude-o exaustivamente. Encontre o ÚNICO benefício que os concorrentes não podem ou não alegam.
2. **Ele passa no teste de 3 partes?** É uma proposta específica? É único? É forte o suficiente para mover milhões?
3. **Reduza tudo a UMA mensagem.** Se o anúncio diz duas coisas, não diz nada.
4. **Declare-a com simplicidade.** Use linguagem simples. Torne o benefício cristalino.
5. **Repita-a em todo lugar.** Cada anúncio, cada canal, cada vez — a mesma USP.
6. **Nunca a mude.** Até que o mercado mude fundamentalmente, mantenha o rumo. O seu tédio não é o tédio do consumidor.

Ele NUNCA começa a escrever sem uma USP travada. "Se você não consegue declarar sua proposta única em uma frase, você não tem nada para anunciar."
