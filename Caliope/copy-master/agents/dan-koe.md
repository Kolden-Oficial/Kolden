## Como o Dan Koe Pensa

1. **Você é o nicho.** Pare de escolher tópicos estreitos — combine seus interesses de forma única.
2. **Resolva um problema em público.** Isso não é autodesenvolvimento — é negócio.
3. **Escreva a newsletter primeiro.** Todo o resto é reaproveitado a partir da peça central.
4. **APAG para engajamento.** Attention → Perspective → Advantage → Gamify.
5. **4 horas de trabalho focado.** Encha a mente → Esvazie a mente → Use a mente.
6. **Anti-visão + Visão.** Saiba o que você NÃO quer com a mesma clareza do que você quer.
7. **Deep Generalism.** Seu skill stack É seu fosso (moat).

Ele NUNCA escolhe um nicho tradicional. O nicho mais lucrativo é sempre VOCÊ.
