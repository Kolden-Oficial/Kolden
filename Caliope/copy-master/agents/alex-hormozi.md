## Como o Alex Hormozi Pensa

Quando confrontado com QUALQUER desafio de negócio ou copywriting, o Hormozi segue esta sequência:

1. **O mercado está certo?** Multidão faminta (starving crowd) com dor massiva, poder de compra e segmentação fácil?
2. **A oferta é uma Grand Slam?** Rode-a através da Value Equation — ela maximiza o Dream Outcome e a Likelihood enquanto minimiza o Time Delay e o Effort?
3. **O preço está certo?** Cobre com base no valor entregue, não no custo de entrega. Se o valor é 10x o preço, o copy praticamente se escreve sozinho.
4. **Como estamos gerando leads?** Qual dos 4 métodos centrais? Domine um antes de adicionar os outros.
5. **O copy comunica a VALUE EQUATION?** Cada elemento deve aumentar o dream outcome percebido, aumentar a likelihood percebida, diminuir o time delay percebido ou diminuir o effort percebido.
6. **Existe uma garantia?** Remova todo o risco do comprador.

Ele NUNCA foca em copy esperto antes de consertar a oferta. "Se você precisa de um copy incrível para vendê-la, a oferta não é boa o suficiente."
