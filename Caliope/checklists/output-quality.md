# Checklist de Qualidade de Saída de Copywriting

**ID do Checklist:** COPY-CL-001
**Referenciado por:** tasks/review.md
**Propósito:** Validar os entregáveis de copywriting quanto à qualidade antes da entrega ao usuário.

[[LLM: INSTRUÇÕES DE INICIALIZAÇÃO

Este checklist valida especificamente a saída de copywriting.

ABORDAGEM DE EXECUÇÃO:
1. Para cada categoria, verifique cada item em relação ao entregável
2. Marque os itens como [x] Aprovado, [ ] Reprovado, [N/A] Não Aplicável
3. Itens CRÍTICOS bloqueiam a entrega; itens não críticos são apenas consultivos

Itens CRÍTICOS são marcados com o sufixo (CRÍTICO).]]

## 1. Título & Gancho

- [ ] O título para o leitor — cria curiosidade, urgência ou uma promessa ousada (CRÍTICO)
- [ ] O parágrafo de lead fisga nas duas primeiras frases (CRÍTICO)
- [ ] O título é específico, não vago ou genérico
- [ ] Os subtítulos guiam o leitor através da peça
- [ ] A abertura aborda diretamente a dor ou o desejo do leitor

## 2. Persuasão & Estrutura

- [ ] Cada frase obriga o leitor a ler a próxima (CRÍTICO)
- [ ] A copy segue um framework lógico de persuasão (PAS, AIDA ou equivalente)
- [ ] Os benefícios são enfatizados acima das características
- [ ] Detalhes e números específicos são usados em vez de afirmações vagas
- [ ] Elementos de prova social, autoridade ou credibilidade estão presentes quando apropriado
- [ ] Objeções são antecipadas e tratadas

## 3. Oferta & CTA

- [ ] A oferta é cristalina — o leitor sabe exatamente o que recebe (CRÍTICO)
- [ ] A chamada para ação é específica, urgente e fácil de seguir (CRÍTICO)
- [ ] Há reversão de risco (garantia, teste gratuito, linguagem de não-obrigação)
- [ ] A escassez ou urgência é lógica e crível, não fabricada
- [ ] A proposta de valor é inconfundível

## 4. Voz & Legibilidade

- [ ] Escrita na linguagem e no nível de leitura do público-alvo
- [ ] Tom conversacional — lê-se como uma pessoa falando com outra
- [ ] Sem jargão, a menos que o público o espere
- [ ] Parágrafos curtos, comprimento de frase variado, fácil de escanear
- [ ] Voz ativa dominante; voz passiva usada apenas intencionalmente

## 5. Qualidade Técnica

- [ ] Gramática, ortografia e pontuação estão corretas
- [ ] Nenhuma afirmação infundada ou juridicamente arriscada
- [ ] Formatação apropriada para o meio (e-mail, LP, anúncio, etc.)
- [ ] Comprimento apropriado para o contexto e a plataforma

## 6. Prontidão para Conversão

- [ ] VOCÊ compraria/clicaria/agiria com base nesta copy? (CRÍTICO)
- [ ] Os gatilhos emocionais são autênticos, não manipuladores
- [ ] A peça tem um único objetivo claro — sem CTAs concorrentes
- [ ] Os bullets estão carregados de benefícios, não de descrições planas

---

## Critérios de APROVAÇÃO/REPROVAÇÃO

**APROVADO:** Todos os itens CRÍTICOS [x] e menos de 3 falhas não críticas.
**REVISAR:** Todos os itens CRÍTICOS [x], mas 3 ou mais falhas não críticas.
**REPROVADO:** Qualquer item CRÍTICO desmarcado.
