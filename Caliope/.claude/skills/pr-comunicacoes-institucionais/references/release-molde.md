# Press release — molde completo com contagens

## Cabeçalho (nunca omitir)

```
Para divulgação imediata
{Cidade, DD de {mês} de AAAA}
```

## Headline (≤ 80 caracteres, verbo forte no presente)

> {Empresa} {verbo forte} {objeto} para {público/mercado} após {contexto quantificado}

Exemplos:
- "Neuros abre 3 clínicas em Curitiba após rodada de R$ 40 milhões"
- "Vale contrata 200 engenheiros para operação híbrida em Belo Horizonte"

## Sub-headline (opcional, 1 linha)

Complementa a headline com um ângulo secundário — nunca repete.

## Lead — 1º parágrafo (≤ 50 palavras, 5W)

> A **{Empresa}**, {descritor de 1 linha}, {verbo forte no presente ou passado próximo}
> {objeto} nesta {momento — semana / mês / hoje} para {público/objetivo}. A iniciativa
> {impacto quantificado / por que agora}, segundo dados de {fonte verificável}.

## Corpo (pirâmide invertida — 250-500 palavras)

### Parágrafo 2 — o que muda para o mercado / cliente
Traduzir a notícia em consequência concreta para quem lê. Aqui entra o "por quê importa".

### Parágrafo 3 — Quote executivo interno (≤ 40 palavras)
Executivo com **nome, cargo, empresa** entre parênteses. Diz algo que **só ele poderia
dizer**:

> "{Frase que revela decisão, aprendizado, dado interno ou visão específica}." — {Nome},
> {cargo}, {Empresa}.

### Parágrafo 4 — dados / prova
1-3 números verificáveis com fonte declarada. Sem fonte → cortar.

### Parágrafo 5 — Quote externo (opcional, ≤ 40 palavras)
Cliente, parceiro, especialista. Adiciona validação de terceiro.

### Parágrafo 6 — Contexto do setor
1 parágrafo situando no macro. Aqui é onde o release ganha ou perde interesse editorial.

## Boilerplate — "Sobre {Empresa}" (40-60 palavras)

Bloco padrão da empresa. Nunca reescrever a cada release. Deve conter: o que a empresa faz,
quando foi fundada, onde opera, tamanho (funcionários / receita se público), site.

## Contato de imprensa

```
{Nome do porta-voz de imprensa}
{Cargo}
{Empresa}
{e-mail}
{telefone com DDD}
```

## Marcação de fim

```
### (ou -30-)
```

## Total esperado

- Release curto: 300-400 palavras (1 página).
- Release completo: 500-700 palavras (1.5 páginas).
- Nunca ultrapassar 800 palavras. Se ultrapassou, é dois releases.
