# Scorecard — ficha de app (App Store / Play Store)

Rubrica 0-10 por componente. Total 0-50. Ficha nota <30 = intervenção urgente.

## 1. Ícone (0-10)

| Nota | Critério |
|---|---|
| 0-3 | irreconhecível em 30px; UI screenshot no ícone; texto ilegível |
| 4-6 | símbolo claro, mas se confunde com outros da categoria |
| 7-8 | forma única + contraste forte; reconhecível em thumbnail |
| 9-10 | vira "signal shape" (você identifica em 0.5s no meio de 20 concorrentes) |

## 2. Título + subtítulo (0-10)

| Nota | Critério |
|---|---|
| 0-3 | só nome de marca, sem keyword ("Zenlo") |
| 4-6 | keyword genérica no subtítulo ("Zenlo — Wellness App") |
| 7-8 | keyword primária + benefício ("Zenlo — Meditação para dormir") |
| 9-10 | keyword de alta intent + público específico ("Zenlo — Meditação para insones") |

## 3. Screenshot 1 (peso duplo — 0-10)

| Nota | Critério |
|---|---|
| 0-3 | tela de onboarding sem legenda |
| 4-6 | screenshot da UI + nome do app |
| 7-8 | hook em legenda grande + 1 elemento visual dominante |
| 9-10 | hook + público + benefício + 1 número real ("4.8★ · 200k users") |

## 4. Sequência 2-5 (0-10)

| Nota | Critério |
|---|---|
| 0-3 | UI cru sem legenda em nenhum slide |
| 4-6 | 3 de 5 slides com legenda |
| 7-8 | segue arco problema → solução → prova → CTA |
| 9-10 | cada slide entrega 1 benefício + 1 prova; ordem testada |

## 5. Descrição + reviews (0-10)

| Nota | Critério |
|---|---|
| 0-3 | descrição = feature list; reviews sem resposta |
| 4-6 | 3 primeiras linhas OK; reviews ★1-★2 respondidos ocasionalmente |
| 7-8 | primeiras 3 linhas puxam para "ver mais"; ★1-★2 respondidos em <48h |
| 9-10 | descrição estruturada em Prova → Feature → CTA; 100% dos ★1-★3 respondidos individualmente |
