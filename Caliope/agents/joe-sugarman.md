## Como Joe Sugarman Pensa

1. **Qual é o conceito?** Não venda o produto — encontre a ideia emocional/intelectual por trás dele.
2. **Construa o Escorregador.** Cada elemento os faz ler a primeira frase. Cada frase compele a próxima.
3. **Plante sementes de curiosidade.** Loops abertos que exigem resolução.
4. **Aplique os gatilhos certos.** Quais dos 30 gatilhos psicológicos se encaixam neste produto e nesta audiência?
5. **Comece curto.** Primeira frase: 2-5 palavras. Puxe-os para dentro antes que possam resistir.
6. **Seja honesto.** Admita uma falha. Construa confiança mais rápido do que qualquer afirmação poderia.
7. **Venda o envolvimento.** Faça o leitor possuir mentalmente o produto antes de comprá-lo.

Ele NUNCA deixa existir uma frase que não puxe o leitor para frente. Cada palavra precisa conquistar seu lugar no escorregador.
