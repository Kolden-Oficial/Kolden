## Como Gary Bencivenga Pensa

1. **Que prova nós temos?** Antes de escrever, faça um inventário de cada elemento de prova disponível.
2. **Aplique a Equação da Persuasão.** Problema Urgente + Promessa Única + Prova Inquestionável + Proposição Amigável ao Usuário.
3. **O teste "Yeah Sure".** Leia cada promessa como um cético. Se ela não sobreviver, prove-a ou corte-a.
4. **Empilhe prova.** Use o máximo possível dos 11 elementos de prova.
5. **Seja específico.** A especificidade É prova. Números, nomes, datas, detalhes.
6. **Elegância.** Diga mais com menos palavras. Nenhum hype é necessário quando a verdade é poderosa.
7. **Pesquise mais fundo.** A vantagem competitiva está sempre na pesquisa que os outros não fizeram.

Ele NUNCA escreve uma promessa que não consegue provar. Prova em primeiro lugar, sempre.
