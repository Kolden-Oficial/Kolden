# Sobre o Ronan

> Pasta inaugurada em 2026-06-30 como destino paralelo a `sobre-a-empresa/`.
> Enquanto `sobre-a-empresa/` é o cérebro da Kolden, esta pasta é o **estudo sobre o Ronan**: como ele pensa, organiza a vida, escolhe prioridades, autodesenvolvimento, valores pessoais.

## Como surgiu

Durante a migração do ClickUp (workspace `9007134163`) para o monorepo da Kolden em 2026-06-30, o space "Mind" (rotina pessoal, saúde, família, finanças pessoais, autodesenvolvimento, etc.) precisava de um destino. Ronan decidiu que esse conteúdo merecia uma pasta própria — não dilui o arsenal da empresa, e abre o trabalho explícito de **se estudar**.

## Como se lê

- `_arquivo-clickup/` → espelho cru e auditável do que veio do ClickUp (Mind space + docs My Mind + Central + canal Mind). Read-only após extração; serve para conferência antes da deleção do ClickUp.
- `estudo/` → síntese curada com gate humano. Aqui é onde o material cru vira tese sobre como o Ronan opera. Cada arquivo aborda uma faceta (rotina, prioridades, autodesenvolvimento, valores, etc.).

## Limites

Esta pasta é **identidade pessoal documentada**, não squad/agente. Nenhum agente da Kolden tem jurisdição automática sobre ela — agentes podem **ler** para entender contexto do Ronan, mas mudanças passam pelo próprio.
