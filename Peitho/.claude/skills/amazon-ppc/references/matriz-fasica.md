# Matriz fásica — Amazon PPC

## Fase Launch (0-90 dias)

| Item | Valor |
|---|---|
| Meta primária | subir organic rank |
| ACOS target | 60-100% |
| TACOS target | 15-30% |
| Duração | 30-90 dias |
| Campanhas ativas | SP Auto + SP Broad + SP Phrase + SP Exact (iniciando) |
| Match type foco | Auto + Broad (research) |
| SB / SD | pouco/nenhum |
| Budget split | 100% SP inicial → 85% SP + 15% SB no fim da fase |
| Métrica de saída | 20-40 reviews + rank top 30 na keyword-âncora |

Sinal de que passou para Growth:
- Organic rank sobe consistente na keyword-âncora.
- ACOS orgânico começa a compensar PPC.
- Review count >20 com rating >4.

## Fase Growth (3-9 meses)

| Item | Valor |
|---|---|
| Meta primária | escala + brand + rank consolidado |
| ACOS target | 30-50% |
| TACOS target | 15-25% |
| Duração | 3-9 meses |
| Campanhas ativas | SP completo + SB static + SB video + SD (introduzido) |
| Match type foco | Exact (top winners) + Broad (novas keywords) |
| SB / SD | 15-25% budget SB, 10-15% SD |
| Budget split | 65% SP / 20% SB / 15% SD típico |
| Métrica de saída | Rank top 5 na âncora + TACOS <20% consistente |

Sinal de que passou para Mature:
- Organic rank top 5 na keyword-âncora + top 20 em 5+ keywords secundárias.
- TACOS <20% por 60+ dias.
- Review count >100 com rating >4.2.

## Fase Mature (270+ dias)

| Item | Valor |
|---|---|
| Meta primária | profitability |
| ACOS target | <25% |
| TACOS target | 8-15% |
| Duração | ongoing |
| Campanhas ativas | tudo, otimizado |
| Match type foco | Exact (80%) + Auto (research contínuo) |
| SB / SD | SB video em brand + SD audience |
| Budget split | 55% SP / 25% SB / 20% SD |
| Otimizações | dayparting + negative list refinada + weekly SQR review |

## Matriz de KPI por fase

| KPI | Launch | Growth | Mature |
|---|---|---|---|
| ACOS | 60-100% | 30-50% | <25% |
| TACOS | 15-30% | 15-25% | 8-15% |
| CTR | 0.3-0.6% | 0.5-1% | 1%+ |
| Conv rate | 5-10% | 10-15% | 15-25% |
| Rank organic (âncora) | 30-100+ | 5-30 | 1-5 |
