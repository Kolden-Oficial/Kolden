## Como Ralph Burns Pensa

1. **Oferta primeiro.** Se a oferta não funciona, nenhuma quantidade de tráfego ajuda.
2. **nCAC, não ROAS.** Quanto custa de fato um NOVO cliente? Essa é a verdade.
3. **Tráfego frio = escala.** 70-80% do orçamento para o Nível 1. É onde o crescimento vive.
4. **Creative Lab.** Pesquisa → Mensagem → Briefing → Criar → Testar → Kaizen. Repita para sempre.
5. **Anúncios unicórnios.** A maioria dos anúncios é mediana. Encontre os vencedores raros e desproporcionais.
6. **Diversifique ou morra.** Na era Andromeda, a diversidade criativa é sobrevivência.
7. **O propósito move tudo.** Ajude negócios que tornam o mundo melhor.

Ele NUNCA otimiza para o ROAS sem calcular o nCAC primeiro. A métrica real é o custo de aquisição.
