# Checklist de Qualidade de Conteúdo Social

**ID do Checklist:** PHEME-CL-001
**Referenciado por:** workflows/wf-conteudo-ate-publicacao.yaml (fase 3), tasks/publicar.md (gate)
**Propósito:** Validar uma peça de conteúdo antes da publicação. É o **gate** que o publisher exige.

[[LLM: INSTRUÇÕES DE INICIALIZAÇÃO

Este checklist valida a saída de conteúdo de social media do squad Pheme.

ABORDAGEM DE EXECUÇÃO:
1. Para cada categoria, verifique cada item contra a peça
2. Marque [x] Aprovado, [ ] Reprovado, [N/A] Não Aplicável
3. Itens CRÍTICOS bloqueiam a publicação; não críticos são consultivos

Itens CRÍTICOS têm o sufixo (CRÍTICO).]]

---

## 1. Gancho

- [ ] Os 3 primeiros segundos (vídeo) ou a primeira linha (texto/carrossel) param o scroll (CRÍTICO)
- [ ] O gancho é específico, não genérico
- [ ] Há um loop aberto ou tensão que segura a atenção
- [ ] Foram consideradas pelo menos 3 variações de gancho

## 2. Valor & Formato

- [ ] A peça entrega valor real (ensina, diverte ou inspira), não só vende (CRÍTICO)
- [ ] Um conceito central claro (não várias mensagens competindo)
- [ ] O formato respeita as regras nativas da rede (duração, proporção, limites de caractere)
- [ ] Vídeo: tem texto na tela (a maioria assiste sem som)
- [ ] Carrossel: um conceito por slide, capa magnética
- [ ] Texto: escaneável, uma ideia por linha

## 3. Salvabilidade & Compartilhamento

- [ ] A peça é feita para ser SALVA ou COMPARTILHADA, não só curtida (CRÍTICO)
- [ ] É uma referência útil (passos, framework, checklist) OU gera identificação/emoção forte

## 4. Marca Kolden

- [ ] Está na voz e no tom da marca Kolden (lente Aglaia) (CRÍTICO)
- [ ] Visual/identidade seguem o brandbook (cores, tipografia, template)
- [ ] A peça pertence a um pilar de conteúdo definido

## 5. Objetivo & CTA

- [ ] A peça tem UM objetivo claro (alcance, salvar, seguir, clicar, vender) (CRÍTICO)
- [ ] Há UM CTA explícito e adequado à rede
- [ ] Sem CTAs concorrentes

## 6. Conformidade & Técnica

- [ ] Sem afirmações falsas, enganosas ou juridicamente arriscadas
- [ ] Respeita as políticas da plataforma
- [ ] Gramática e ortografia corretas
- [ ] Hashtags/keywords adequadas à rede (quando aplicável)

## 7. Prontidão para Crescimento

- [ ] VOCÊ pararia o scroll e interagiria com isso? (CRÍTICO)
- [ ] O gancho é testável (há variações para A/B)
- [ ] A peça se conecta a uma série/pilar (consistência), não é isolada

---

## Critérios de APROVAÇÃO/REPROVAÇÃO

**APROVADO:** Todos os itens CRÍTICOS [x] e menos de 3 falhas não críticas. → Liberado para o publisher.
**REVISAR:** Todos os CRÍTICOS [x], mas 3+ falhas não críticas. → Ajustar antes de publicar.
**REPROVADO:** Qualquer item CRÍTICO desmarcado. → Devolver ao especialista. Publisher NÃO publica.
