# Bilibili — vídeo de nicho vertical + comunidade Gen-Z

Bilibili é a plataforma de vídeo mais próxima do YouTube ocidental em cultura, mas com
uma camada exclusiva: **danmaku** (comentários flutuantes sincronizados por timestamp) e
o culto ao **UP主** (uploader/criador). Diferente do Douyin (short-video/algorítmico), o
B站 recompensa vídeos médios/longos (6-20 min), séries e comunidade.

## Passo 1 — Entender o algoritmo do B站 (diferente do Douyin)

Bilibili premia **retenção completa** e **interação assíncrona** (danmaku, favoritos,
compartilhamento, coin/moeda). O algoritmo pesa 5 sinais principais (nomenclatura oficial):

1. **播放 (views)** — visualizações
2. **弹幕 (danmaku)** — comentários flutuantes, principal sinal social
3. **投币 (coin)** — usuário "doa" 1-2 moedas (recurso escasso, gesto de mérito)
4. **收藏 (favorite)** — bookmark
5. **分享 (share)** — compartilhar externo

Vídeos que "tri-conectam" (三连: like + coin + favorite) têm boost sistêmico. O algoritmo
distribui em ondas: primeira onda para seguidores + tag, segunda onda para categoria,
terceira para explore. Cada onda depende do CTR + retenção da anterior.

## Passo 2 — Escolher a Zona (分区)

B站 é organizado em 22 zonas primárias com sub-zonas. Escolha errada = distribuição ruim.

Principais zonas B2B/marca:
- **知识 (Knowledge)** — ciência, tech, humanas, educação, vida-longa (LIFE)
- **数码 (Digital)** — tech reviews, hardware, apps
- **科技 (Tech)** — inclui AI, software, "IT interviews"
- **生活 (Life)** — vlog, food, DIY
- **时尚 (Fashion)** — beauty, outfits, lifestyle
- **游戏 (Gaming)** — reviews, tutoriais, streams
- **动画 (Animation)** — anime, MAD, tutoriais de arte
- **影视 (Film & TV)** — resenhas, análises

Marca B2B/tech geralmente entra em 知识 > 科学科普 (science pop) ou 数码 > 手机平板 (phones/tablets).
Escolher a subzona onde o público-alvo já assiste é mais importante que "melhor CPM".

## Passo 3 — Arco narrativo de vídeo B站 (6-20 min)

Ao contrário do TikTok/Douyin (gancho 3s), o B站 tolera abertura de 15-45s se a promessa
for clara. O arco padrão do UP主 competitivo:

1. **Cold open (0-15s)** — pergunta polêmica, tese contra-intuitiva ou demo do
   resultado final. Cria motivo para ficar.
2. **Sinal de qualidade (15-30s)** — mostra que houve trabalho (experimentos, dados,
   entrevistas, filmagem cara). Sinaliza "vídeo de coin" (投币-worthy).
3. **Índice/promessa (30-60s)** — "hoje vamos ver 4 coisas: A, B, C, D". B站 tem
   chaptering nativo por timestamp — use.
4. **Desenvolvimento (60s-15min)** — capítulos com cortes secos, gráficos densos,
   citações on-screen. Densidade de informação é o cerne (o inverso do TikTok).
5. **Payoff + call para 三连 (final 15-30s)** — "se ajudou, deixa um 三连 pro
   algoritmo espalhar". Chamada explícita é aceita/esperada (não cringe como no
   YouTube ocidental).

**Duração ótima:** 8-12 min para conteúdo Knowledge; 4-8 min para Digital/Tech reviews;
15-25 min para deep-dive (documentário/análise).

## Passo 4 — Engagement design por danmaku (弹幕)

Danmaku é o que separa B站 de qualquer outra plataforma no mundo. É um sinal social e
uma camada de storytelling.

**Design de gatilhos de danmaku por timestamp:**

| Momento | Gatilho | Danmaku esperado |
|---|---|---|
| 0-15s (cold open) | Pergunta direta ao viewer | "1", "在" ("presente"), reação inicial |
| Antes de revelar dado surpreendente | "Adivinha quanto foi?" | Chutes numéricos |
| Ponto controverso | Afirmação forte | Debate (concordo/discordo) |
| Piada interna do nicho | Referência específica | Meme code (ex.: "空 前 绝 后") |
| Momento emocional | Silêncio + música | "破防了" (quebrou minha defesa), "泪目" (olhos marejados) |
| Antes do payoff | "Isso vai chocar você" | Suspense, "?" |
| Final | Call para 三连 | Confirmação de 三连 |

**Regra prática:** todo minuto do vídeo deve ter 1 gatilho intencional de danmaku. Sem
danmaku, o vídeo "morre" — o algoritmo interpreta silêncio como baixa qualidade.

## Passo 5 — Capa (封面) e título — mais importantes que o vídeo

Como no YouTube, capa + título > vídeo. B站 tem regras próprias:

- **Capa 16:9, 1146×717** ou proporção equivalente; densa de informação (texto grande,
  rosto expressivo, ou objeto icônico).
- **Título ≤ 30 char**; use símbolos (【】, 「」, ‖) para categorizar; termine com gancho
  de curiosidade (?, !!, "…真的假的?").
- **Tags** — B站 permite 10 tags; use 3 tags amplas (zona) + 4 tags específicas + 3 tags
  de UP/série.

## Passo 6 — Monetização

- **Creative Incentive Plan (创作激励)** — pagamento por 1000 views (varia R$0,50-R$3,00/1000
  views); precisa de canal certificado e conteúdo original.
- **Charging (充电)** — Patreon-like; fãs doam mensalmente. Bom para UP主 educacionais.
- **Live streaming (直播)** — gorjetas (贵族/礼物) + PPV para lives especiais.
- **Merch e curso** — via Bilibili Mall ou link off-platform (regras variam).
- **Sponsored ("恰饭")** — mercado maduro; declarar patrocínio no início do vídeo
  (拒绝隐性广告 — cultura anti-oculto).

## Compliance & risco

- **Verificação da conta** — para operar como marca ("企业号"), submeter documentos
  corporativos (business license) e nomear operador local.
- **VPN não é canal legítimo** — publicar via biliup (draft-first, publicação humana) ou
  interface web com IP chinês/CDN autorizado.
- **Censura ativa** — palavras-gatilho (política, saúde, "conteúdo vulgar") reviewer
  humano + automatizado; conteúdo pode ser "锁定" (locked, sem distribuição) mesmo
  publicado. Evitar termos sensíveis ou usar eufemismos consagrados.
- **Copyright estrito** — reuso de música/imagem exige licença; B站 é proativo em takedown.
- **Segredos** (biliup token, API key) via Infisical.

## Fluxo padrão da skill (resumo)

1. **Diagnóstico**: zona-alvo escolhida? UP主 concorrentes identificados? Retenção
   média deles?
2. **Roteiro** — cold open + índice + 4 capítulos + payoff, com gatilhos de danmaku
   mapeados por timestamp.
3. **Produção** — capa 16:9 densa, título com símbolo, 10 tags (3+4+3).
4. **Publicação draft-first** via biliup, revisão humana antes de publicar.
5. **Monitoramento nas primeiras 24h** — se retenção < 40% no minuto 1, o vídeo já
   morreu; retenção > 55% na média = viral candidato.
6. **Interação nos primeiros 48h** — responder danmaku e comentários fixados; puxa
   segunda onda de distribuição.

## Checklist da skill
- [ ] Zona/subzona correta escolhida
- [ ] Retenção projetada > 40% no minuto 1 (via cold open testado)
- [ ] 1 gatilho de danmaku por minuto mapeado no roteiro
- [ ] Capa densa + título com símbolo + 10 tags (3 zona + 4 específicas + 3 UP/série)
- [ ] Call para 三连 no payoff
- [ ] Segredos no Infisical (biliup)
- [ ] Publicação via ferramenta oficial (biliup ou web), não automação bloqueada
- [ ] Interação nas primeiras 48h agendada (responder danmaku/comment)
