# Kuaishou — 老铁 grassroots + 下沉 lower-tier + community-first

Kuaishou (KS) é o "primo humilde" do Douyin — mesma categoria (short-video + livestream
+ e-commerce) mas com **cultura oposta**: onde o Douyin é aspiracional e polido, o KS é
comunitário e cru. Domina os mercados 下沉 (tier 3-5 e rural, ~700M dos ~1.4B chineses)
e é canal decisivo para categorias de volume: FMCG barato, moda popular, agri, ferramentas,
food homemade, farmácia OTC.

## Passo 1 — Cultura 老铁 (lǎotiě): a diferença fundamental

老铁 significa literalmente "velho ferro" — no dialeto do nordeste, apelido carinhoso para
"amigo/parceiro". Na cultura Kuaishou, virou o pronome que host usa para chamar a audiência.
Marca essa vibração:

- **Peer-to-peer, não broadcast** — o creator conversa "como se fosse com um amigo", não
  performa "para uma audiência".
- **Autenticidade > polimento** — vídeo estilo caseiro (celular na mão, cenário real) vira
  autoridade, não fraqueza.
- **Community-first** — comment section é lugar de conversar, não só reagir. Creator
  responde por nome, referencia comentários anteriores, chama o fan de 老铁.
- **Sinceridade sobre venda** — "esse produto é bom mas não é para todo mundo" vende mais
  no KS do que hype ilimitado (que funciona no Douyin/Xiaohongshu).

**Quem não deve estar no KS:** marca premium ultra-aspiracional, luxury (Chanel, Gucci —
tem presença mas ínfima), tech B2B enterprise.

**Quem deve estar:** FMCG barato/mid-tier, food, moda popular, health OTC, agri, small
tools, casa, cosméticos entrada, snacks, chá/café mid, seguro simples, edu vocacional.

## Passo 2 — Algoritmo do KS (diferente do Douyin)

Kuaishou historicamente é "descentralizado" — distribui tráfego de forma mais equilibrada
entre creators pequenos e grandes (política de "普惠" — inclusão). Isso muda no tempo,
mas o viés persiste.

**Sinais principais:**
1. **Completion rate** — como no Douyin, mas com peso menor.
2. **Repeat share (二次分享)** — quando o mesmo vídeo é reencaminhado em chat WeChat/QQ.
   Sinal forte, específico do KS.
3. **Comment depth** — não só número de comments, mas trocas com o creator (thread).
4. **Live entry rate** — se um creator faz live, view do vídeo → clique-in na live é
   pesado.
5. **Long-term retention da conta** — % de seguidores que reveem vídeos > 24h depois.
   KS premia relacionamento contínuo mais do que Douyin.

## Passo 3 — Livestream commerce no KS (o coração do modelo)

Se Douyin é 60% vídeo + 40% live, KS inverte: **~70% do GMV vem de live commerce**. O
formato é diferente:

- **Duração longa** — 6-12h por sessão, hosts em revezamento.
- **Tom conversacional** — não script; "papo com o 老铁 sobre esses produtos".
- **Provas físicas** — abrir a caixa, cortar a fruta, provar o produto na câmera.
- **Preço baixo + volume alto** — GMV vem de ticket médio RMB 30-100, não RMB 300+.
- **Retorno grátis + SLA claro** — KS penaliza dispute rate mais que Douyin.
- **KOL nativo Kuaishou** — hosts próprios do KS (Simba/辛巴, Xin Youzhi/信有志) fazem
  live que vendem RMB 100M+ em uma noite. Não são os mesmos KOL do Douyin/RED.

## Passo 4 — Estrutura de conteúdo (vídeo curto que abre live)

O vídeo curto no KS serve principalmente para trazer viewer para a live.

- **Formato tease para live:** 15-30s mostrando "preview" de produto que estará na live
  daquela noite; CTA "hoje 20h ao vivo, tem esse 15% off pro 老铁".
- **Formato daily life:** creator mostra rotina, produto entra organicamente (sem
  vender). Constrói vínculo. Frequência 2-4/dia.
- **Formato "教你" (te ensino):** how-to prático (receita, dica agri, remedy caseiro),
  produto como coadjuvante. Alta retenção.
- **Formato "老铁福利" (benefício pro 老铁):** promo exclusiva de seguidor, cupom,
  give-away. Alta conversão pra follow.

Duração: 15-45s. Legenda burnt-in em Mandarim padrão + cor saturada. Não usa muitos efeitos
"cinematográficos" (é anti-cultura KS).

## Passo 5 — Tabela comparativa Kuaishou vs Douyin

Regra prática: **não são intercambiáveis.** Mesmo criativo raramente performa em ambos.

| Dimensão | Douyin (抖音) | Kuaishou (快手) |
|---|---|---|
| **Vibe** | Aspiracional, polido, viral | Comunitário, cru, autêntico |
| **Cidade dominante** | Tier 1-2 (Beijing/SH/GZ/SZ) | Tier 3-5 + rural |
| **User demo** | 18-35 profissional urbano | 25-45 blue-collar/rural |
| **Distribuição algorítmica** | Explore-heavy (fan-out para desconhecidos) | Follower-heavy (fan-out lento) |
| **Live GMV %** | ~40% do GMV | ~70% do GMV |
| **Ticket médio** | RMB 80-300 | RMB 30-100 |
| **Content vibe** | Cinematográfico, edit denso | Cru, sem edit, celular na mão |
| **KOL model** | Múltiplos verticais + brand partnerships | Mega-KOLs "família" (Simba style) |
| **Verticais dominantes** | Beauty, apparel premium, tech, F&B urbano | FMCG, food, moda popular, agri, OTC |
| **Payment platform integration** | Douyin Pay + WeChat + Alipay | Kuaishou Pay + WeChat + Alipay |
| **Idioma social** | 家人们 ("family") | 老铁 ("bro/amigo") |

## Compliance & risco

- **Verificação de marca** — igual Douyin, "企业号" com business license chinesa.
- **VPN não é canal legítimo** — publicar via interface oficial ou parceiro MCN.
- **Censura ativa** — palavras-gatilho semelhantes ao Douyin, com ênfase adicional em
  claims de saúde/agri (categorias fortes no KS). Cuidado com claims de fertilizante,
  remédios caseiros, health OTC — categoria super-fiscalizada.
- **Category compliance** — food precisa QS/SC; cosmético precisa CFDA number in-video;
  agri produto precisa 农药 registration; farm OTC precisa CFDA + prescription warning.
- **Dispute rate** — KS penaliza dispute > 3% do GMV; qualidade de fulfillment é KPI.
- **Segredos** (Kuaishou Open Platform, magnetic engine — 磁力金牛 API) via Infisical.

## Fluxo padrão da skill (resumo)

1. **Fit check** — a marca faz sentido no KS? (usar checklist tier + categoria + vibe).
2. **Estratégia dual: vídeo curto (2-4/dia) + live diária** — se marca ainda sem live,
   agendar debut após 4-6 semanas de vídeo curto para construir base.
3. **Escolher host** — não usa host aspiracional; usa host acessível, autêntico, com
   sotaque regional se possível.
4. **Roteiro live** — não script rígido; roteiro em 6-8 bullet-points com produto do dia,
   preço-âncora, momento de give-away.
5. **Produção vídeo** — celular na mão, cenário real, legenda burnt-in, duração 15-45s.
6. **Monitoramento** — completion rate, repeat share, comment depth, entry rate para
   live, dispute rate.
7. **Paid amplify** via Magnetic Engine (磁力金牛) só depois de orgânico validar retenção
   > 50% e engagement > 5%.

## Checklist da skill
- [ ] Fit da marca com cultura KS validado (não é qualquer marca)
- [ ] Host escolhido tem vibe 老铁 (não aspiracional demais)
- [ ] Dual-track vídeo curto + live agendado
- [ ] Vídeos curtos com formato "tease para live" ou "daily life" ou "教你"
- [ ] Legenda burnt-in + celular na mão + sem over-edit
- [ ] Compliance CFDA/QS/农药 verificado por categoria
- [ ] Dispute rate < 3% monitorado
- [ ] Credenciais Kuaishou Open + Magnetic Engine no Infisical
- [ ] Publicação via canal oficial (não bot)
