# Livestream Commerce — o formato que redefiniu o e-commerce

Live shopping é a fusão entre entretenimento e checkout. Na China, ~20% do GMV
online é livestream. Fora da China, TikTok Shop Live cresce 3x ao ano. Não é
"mais um canal"; é a arma de venda direta mais eficiente para preço-alvo <$100.

## Antes de começar
Levante:
- **Produto/portfólio** — SKU, ticket médio, margem.
- **Plataforma-alvo** — TikTok Shop Live (US/UK/SEA), Douyin/Kuaishou/Taobao
  (China), YouTube Live Shopping, Amazon Live, Meta Channels.
- **Host disponível** — funcionário interno? Fundador? Talento contratado?
- **Cadência** — 1x/semana (validação), 3-5x/semana (crescimento), diária (escala).
- **Meta principal** — GMV, ROAS, ou brand + growth de conta?

## Funil de conversão em 4 etapas (o mapa de dor)

```
Impressões → View → Engage → Payment
   ↑           ↑        ↑          ↑
   Thumbnail  Hook    Interação  Oferta ao vivo
   +título    +ritmo  +confiança +urgência
```

| Etapa | Métrica | Alavanca | Benchmark saudável |
|---|---|---|---|
| Impressões | Reach da live | Thumbnail + título + tag | Depende da conta |
| View | Views únicos | Hook 30s + tema | View rate ≥5% do reach |
| Engage | Watch time + likes + adds | Ritmo + demonstração | Watch time médio ≥3min |
| Payment | GMV + AOV | Oferta + urgência + host | Conversion rate 1-5% (Ocidente), 5-15% (China) |

## Host training (o único fator não-negociável)

Live sem host preparado é gasto seco. Treinamento em 5 dimensões:

### 1) Persona
- **Autenticidade > polido.** Host precisa ser reconhecível — vulnerabilidade,
  opinião, gosto pessoal.
- **Especialista OU curador OU entertainer** — escolher e assumir.
- **Aparência**: cenário legível, roupa que não vibra na câmera, iluminação uniforme.

### 2) Energia
- Curva alta constante — não picos e vales.
- **Regra do "chá quente"**: bebida quente na mão. Muda o tom da voz e disfarça pausa.
- Nunca ficar parado — mover objeto, gesticular, mudar posição.

### 3) Pacing (o mais difícil)
- **Trocar de assunto/produto a cada 90-180s**. Feed algorítmico + audience
  rotativo obriga.
- **Recap a cada 5min**: "quem entrou agora, o que estamos mostrando é…"
- Nunca esperar chat responder mais de 5s — o que ficar > 5s vira "dead air".

### 4) Interação
- Ler nomes: "obrigada Marina, boa noite!" — muda taxa de comentário 2-3x.
- Responder pergunta com produto na mão, não teoria.
- Reagir ao chat com naturalidade — sem forçar "escreve 1 no chat".

### 5) Vender (o pulo)
- **Contexto → benefício → prova → oferta → ação.** Nunca só preço.
- **Urgência real** (estoque limitado, código expira ao fim da live).
- **Demo física** — mostrar, testar, comparar.
- **Retirar objeção AO VIVO** — a pessoa pergunta "cabe em X?" → mostrar cabendo.

## Operação de live room (roles + run-sheet)

### Roles mínimos (equipe de 3)
- **Host** — na câmera, apresenta e vende.
- **Producer** — controla câmera, luz, mudança de produto, mostra número na tela.
- **Chat manager** — responde chat, filtra perguntas para o host, monitora KPI.

Para escala (equipe de 5+):
- **Co-host** — segunda voz, brinca, cria química.
- **Behind-the-camera** — arruma próximo produto, cronograma.
- **Analista** — monitora dashboard em tempo real, sinaliza slot que está caindo.

### Run-sheet (esqueleto de 60-90min)

| Tempo | Bloco | O que rola |
|---|---|---|
| 0-3min | Warmup | Host apresenta, chama chat, mostra o que vai rolar |
| 3-8min | Produto A (hero) | Demo + oferta + código de urgência |
| 8-12min | Chat interação | Responde perguntas, mostra provas |
| 12-17min | Produto B | Demo + oferta |
| 17-22min | Chat + recap | "Quem entrou agora…" |
| 22-27min | Produto C | Demo + oferta |
| ...continua em ciclos de ~10min | | |
| Últimos 5min | Fecha | Recap ofertas, urgência final, empurra follow |

## Mecânica de oferta ao vivo

- **Preço só na live** — desconto visível apenas durante a transmissão.
- **Bundle relâmpago** — combo aparece nos últimos 3min de cada bloco.
- **Cupom que sobe pelo chat** — chat manager solta cupom em texto simples.
- **Estoque ao vivo** — número decrescendo na tela cria urgência real.
- **Bônus por volume** — "quem comprar 2, ganha X".

## Plataformas — quirks importantes

- **TikTok Shop Live**: alavanca de descoberta forte (algoritmo empurra para não-followers). Precisa produto aprovado + pixel Shop. Comissão 5-8%.
- **Douyin (China)**: rei do mercado; Qianchuan (Ads) alimenta live com tráfego pago. Host reconhecido e "brand day" são a norma.
- **Kuaishou (China)**: base rural/tier 3-4; relacionamento host-viewer é a moeda.
- **Taobao Live**: mais alto ticket + brand rooms; dominada por top hosts.
- **YouTube Live Shopping**: video + comércio; forte para hero product de longa demo.
- **Amazon Live**: complementar ao PPC — funciona bem para demonstração de produto único.
- **Meta Channels**: emergente em US; combinar com Reels + Ads.

## Cadência e crescimento

- **Semana 1-4** (validação): 1 live/semana, mesma janela horária, mesmo host. Meta: aprender curva de retenção + CPA da live.
- **Semana 5-12** (crescimento): 3 lives/semana; testar bloco de horário + host secundário.
- **Semana 13+** (escala): 5-7 lives/semana; alavanca de Ads (Qianchuan, TikTok Live Ads).

## Anti-padrões

- Host sem treino em câmera — mata a energia.
- Só falar preço — vira feirão sem conversão.
- Live esporádica — algoritmo não engaja com quem só aparece 1x/mês.
- Sem chat manager — perguntas sem resposta = zero conversão.
- Zero demo física — dá a mesma vibe de anúncio ruim.
- Ignorar métricas de watch time — atacar só GMV mascara o funil.

## Saída
1. **Estratégia por plataforma** com 1 escolhida como principal.
2. **Perfil de host** + plano de treino (4 semanas).
3. **Run-sheet template** de 60-90min.
4. **Mecânica de oferta** — script de urgência + bundle.
5. **Cadência semanal** + escala em 90 dias.
6. **Dashboard live** — 4 KPIs monitorados ao vivo (view rate, watch time, add-to-cart, GMV).
