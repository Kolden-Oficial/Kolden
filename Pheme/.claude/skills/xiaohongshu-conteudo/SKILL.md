# Xiaohongshu (小红书 / RED) — lifestyle + shopping discovery

Xiaohongshu (小红书 = "livro vermelhinho", em inglês RED) é a plataforma de descoberta
de brand da geração 18-35 chinesa urbana — dominada por mulheres tier 1-2 mas com
crescimento robusto em outras demografias. É o **motor de "种草" (zhòng cǎo — plantar
grama)**, o conceito canônico chinês de shopping-discovery pré-compra. Se marca de beauty,
skincare, fashion, home, food, travel, wellness não está no RED, praticamente não existe
na China urbana.

## Passo 1 — Formato canônico: 6 imagens + caption longa

RED é imagem-centric. O post-padrão que performa:

- **Cover (capa)** — 3:4 vertical, com texto grande sobreposto (título do post na
  imagem, não só na caption). Formato "kv com texto" ganha CTR muito acima de imagem
  clean.
- **Imagens 2-6** — sequência com narrativa: "before → applying → mid → after → tip →
  final look" para beauty; "location wide → detail → outfit → interaction → moment →
  wrap" para travel.
- **9-fold layout consistency** — cor + font + framing do KV virou "brand code" de
  criadores; marca deve ter template consistente.
- **6 imagens é o sweet spot** — pesquisa em top-1000 posts mostra pico de engagement em
  4-8 imagens; 6 é o mais frequente entre viral.

**Caption:**
- **150-500 chars** (não muito curta, não excessiva).
- **Título repetido no início** com hashtag; corpo em 3-5 parágrafos curtos com emoji
  sinalizando seções.
- **Hashtags no fim** — 5-15 hashtags (mix de broad + long-tail + branded).

## Passo 2 — 4 formatos que funcionam (não invente)

RED premia formatos claros e reproduzíveis:

1. **Testimonial / diário pessoal** ("um dia com X", "testei por 30 dias") — vibe autêntica,
   sem edição excessiva. Volume dominante.
2. **How-to / passo-a-passo** ("como fazer X", "5 dicas de Y") — screenshot + numeração.
   Alta save rate.
3. **Comparação / review** ("A vs B", "top 5 X sub RMB Z") — RED premia decisão-de-compra
   utility. Alta comment rate.
4. **Aesthetic mood / inspirations** ("estética Y estilo Z", "outfit para X ocasião") —
   pinterest-like. Alta share rate.

## Passo 3 — Trend riding + aesthetic storytelling

RED é onde a estética viraliza. Trend riding é core, não opcional.

- **Trend inbox diário** — monitorar #热门话题, categoria explore, top-1000 semana.
- **Trends chegam em ondas de 3-14 dias** — pegar D1-D5 é ouro; D6-D10 é morno; D11+ é
  cringe.
- **Aesthetic categories** (com nomenclatura chinesa própria):
  - 清冷 (qīng lěng — cool aesthetic minimalista)
  - 温柔 (wēn róu — gentle/warm)
  - 复古 (fù gǔ — retro/vintage)
  - Y2K
  - 多巴胺 (dopamine, bright colors)
  - 老钱风 (old money aesthetic)
  - 显白 (xiǎn bái — brightening for asian skin tone)
  - "citycore", "coastal grandmother CN version"...

Marca deve saber onde encaixa (ou como propor uma sub-estética própria).

## Passo 4 — KOC army > KOL (contra-intuitivo)

RED é o único canal chinês onde **KOC (Key Opinion Consumer) > KOL** por volume e por
resultado. O algoritmo distribui de forma relativamente equalitária (comparado a Douyin/Weibo).

- **Recruta 50-500 KOCs mid/long-tail** (1k-100k followers) por campaign.
- **Compensação típica:** produto grátis + RMB 200-2000 por post + comissão CPS (custo por
  sale via cupom code).
- **Brief e não script** — orientação de mensagem sem force de wording; autenticidade é
  vantagem competitiva do RED.
- **Volume + variação** = distribuição + credibilidade sistêmica.
- **1-3 top-KOL** para brand halo (não conversão), preferencialmente celebrity/influencer
  já credibilizada no vertical.

Marcas erram brutalmente contratando 1 mega-KOL RMB 500k por 1 post e esperando resultado.
Modelo é o inverso: 100 KOCs × RMB 1k = RMB 100k = 100 pontos de contato > 1 KOL alta.

## Passo 5 — Algoritmo e cold-start

RED distribuí em ondas com peso muito em:
- **Save rate (收藏率)** — sinal #1. Post é "salvo pra reler/comprar depois".
- **Comment quality** — comment que continua a discussão, não emoji-reply.
- **Cover CTR** — passa em explore/search.
- **Read completion** — se o user chega no fim (imagens + caption).
- **Follower conversion** — dos que viram, quantos seguem.

**Cold-start:** primeiras 4-6h decidem. Post que consegue save rate > 5% + comment > 20 na
primeira janela avança. Sem essa validação, morre em 100-500 views.

## Passo 6 — Ban de linkout + como converter

RED **NÃO PERMITE link out** para site externo em post regular. Isso muda tudo:

- **Conversão obrigatória via RED-owned properties:**
  - RED Store (小红书店铺) — e-commerce nativo (Aug 2024 lançado como canal primário).
  - RED Live (直播) — live commerce.
  - "笔记带货" — link direto do produto RED Store no fim do post.
  - CPS code / cupom code no comment (não link).
- **Off-platform destino:**
  - WeChat via QR (não link)
  - Tmall via search + brand keyword no comment ("busque X no Tmall")
  - Nome do brand/produto puro (recall test)

Consequência: **RED força construir brand recall**, não link-tracking. Marca que investe em
RED colhe em search Tmall/Douyin dias depois.

## Passo 7 — Mix editorial (regra 70/20/10)

Anexo "Mixes de mercado" da `matriz-de-conteudo` cobre XHS:
- **70% lifestyle** — inspiração, aesthetic, personal narrative.
- **20% trend riding** — hop na trend do momento.
- **10% brand promo** — launch, oferta, KV.

Mais de 10% promo = penalidade de distribuição.

## Compliance & risco

- **Verificação da conta** — marca precisa "专业号" (professional/brand account) + business
  verification.
- **VPN não é canal legítimo** — operar via interface oficial ou parceiro autorizado
  (xhs-mcp para draft-first).
- **Censura ativa** — palavras-gatilho + revisão humana. Political, health medical claims,
  banned products, "过度美颜" (excessive beauty filter falsa) sob review. RED tem
  compliance rigorosa em beauty claims (FDA-equivalent CFDA needed) e financial claims.
- **Advertising labels** — post pago obrigatório com label "赞助" (sponsored) ou "商务
  合作" (business collab). Detected non-disclosure = fine + shadowban.
- **Comment moderation** — comment inapropriado (spam, link WeChat, contato pessoal) é
  removido rapidamente; sistema pesado.
- **Segredos** (RED API token, ADS console) via Infisical.

## Fluxo padrão da skill (resumo)

1. **Diagnóstico** — a marca faz sentido na RED? (categoria + demo + margem para KOC
   compensation).
2. **Estratégia mix** — 70/20/10 lifestyle/trend/promo.
3. **KOC army** — 50-500 KOCs mid/long-tail contratados + brief.
4. **Trend inbox** semanal.
5. **Formato canônico** — 6 imagens + caption 150-500 chars + hashtags.
6. **Conversão** via RED Store / cupom / brand recall (não link out).
7. **Publicação draft-first** via xhs-mcp ou interface oficial.
8. **Monitoramento cold-start (4-6h)** — save rate > 5%, comment > 20; se não bater,
   morreu.
9. **KPI mensal** — save rate, comment quality, follower growth, cross-platform search
   lift (Tmall search, Baidu search).
