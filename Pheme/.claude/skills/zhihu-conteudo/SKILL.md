# Zhihu — Q&A authority + Columns + thought leadership

Zhihu é onde a China educada busca resposta profunda. Fundado em 2011 como Quora
chinês, hoje é uma plataforma híbrida (Q&A + Columns + Live + Video) com ~100M MAU e
alta concentração de audience "tier 1 educado, decisor B2B, tech-savvy". Ranquear em
Zhihu = trust building + Baidu SEO indireto (Zhihu answers ranqueiam pesado no Baidu).

## Passo 1 — Anatomia do Zhihu (o que a marca opera)

- **Answers (答案)** — resposta a pergunta existente. Volume principal.
- **Questions (问题)** — criar pergunta (moderado, difícil para brand).
- **Columns (专栏)** — long-form editorial próprio (blog-like) dentro da conta.
- **Ideas (想法)** — post curto tipo Twitter (menor peso).
- **Live (知乎 Live)** — sessão de audio/video pago ou grátis (Q&A ao vivo).
- **Roundtable (圆桌)** — hosted discussion.
- **Follow (关注)** — user pode seguir tópico (话题) + user + column + pergunta.
- **Salt Selection (盐选)** — programa de creator premium com paywall.

## Passo 2 — Answers: a fundação (não Columns)

**Answers > Columns** em volume, discovery e authority. Column sozinho fica invisível;
answer bom escala.

### Estrutura canônica de answer (2.000-8.000 chars)

- **Opening — thesis em 1-3 linhas** — "TLDR" em pt-BR. Chinês letrado gosta de ver a
  posição de cara.
- **Prova de autoridade — 2-4 linhas** — "sou X, trabalho em Y, ancora minha resposta em
  Z". Não humble-brag; sinaliza credibilidade.
- **Corpo estruturado — 3-7 seções** — usando H2/H3, listas numeradas, imagens.
- **Data/example concreto** — quantificado ("em 2024 medimos X em 50 casos").
- **Counter-take** — "muitos dizem A, mas na verdade B" — sinal de originalidade.
- **Closing — payoff + call sutil** — "espero que ajude; sigo por aqui pra falar mais de
  X" (não link out — Zhihu penaliza).

### Elementos que rankeiam

- **Upvote (赞同)** — sinal #1. Answer com > 50 upvote em 24h avança em discovery.
- **Save (收藏)** — sinal de "vou reler" — muito pesado para B2B/tech.
- **Comment com engagement — quando author responde a comment, discovery boost.
- **Read completion** — Zhihu mede scroll até o fim; answer longo mas raso = penalty.
- **External backlink** — quando outra plataforma linka pro Zhihu answer, ganha peso.

## Passo 3 — Seleção de perguntas por scorecard de impacto

Não responda qualquer pergunta. Aplique score. Fórmula canônica:

```
impacto = (views_da_pergunta × engagement_rate × relevância_para_marca)
         / (concorrência_de_answers_existentes × tempo_para_produção)
```

Componentes:
- **views_da_pergunta** — Zhihu mostra views total; > 100k = high; > 1M = golden.
- **engagement_rate** — upvotes / views das top-3 answers existentes; > 5% = quente.
- **relevância_para_marca** — 1-10 (score humano; a pergunta toca nossa área?).
- **concorrência** — número de answers > 500 upvotes; > 5 answers já dominantes = perdemos
  na chegada.
- **tempo_para_produção** — h necessárias para produzir answer de qualidade.

**Regra prática:** priorize perguntas com 100k-2M views, top-answer com < 3.000 upvotes,
concorrência de < 5 answers dominantes, relevância ≥ 8. Isso é onde authority se instala.

## Passo 4 — Columns (专栏): long-form próprio

Columns são o "Medium do Zhihu". Menos discovery orgânico que answers, mas úteis para:

- **Series estruturadas** ("Fundamentos de X em 10 partes").
- **Thought leadership editorial** (posições, análises).
- **Cross-referência** — answers linkam para Column como aprofundamento.
- **SEO Baidu** — Columns são ótimo landing para query informacional em Baidu.

Cadência: 1-2 columns/semana; 2.000-5.000 chars cada.

## Passo 5 — Zhihu Live + Roundtable (monetização)

- **Zhihu Live** — audio/video session (30-90 min). Pago (RMB 9.9-999) ou grátis. Bom para
  B2B thought leader — captura audiência qualified.
- **Roundtable (圆桌)** — hosted discussion com 3-5 experts em torno de tema. Marca patrocina;
  ganha branded roundtable.
- **Salt Selection (盐选) membership** — creator premium com paywall. Alto barrier para
  entrar (Zhihu convida).
- **Brand answer** — brand paga Zhihu para labelar answer como "商业推广". Baixa credibilidade
  vs answer orgânico; usar cirurgicamente.

## Passo 6 — Cadência e estratégia de conta

- **Perfil da conta:** individual (nome do specialist da marca) > brand-name puro.
  Chineses trustam pessoa, não logo em Zhihu. Ex.: "李明 · Head of Growth @ Marca X".
- **Cadência:** 2-4 answers/semana + 1 column/semana + 1-2 Live/mês para conta ativa.
- **Long-game** — Zhihu não é hop; leva 6-12 meses de consistência para virar authority
  reconhecida.
- **Community engagement** — responder comment, ajudar em outros answers do vertical
  (crédito acumula).
- **Cross-linking interno** — link entre próprias answers e columns; Zhihu premia network
  effect próprio.

## Compliance & risco

- **Verificação de identidade + credentials** — para credibilidade máxima, Zhihu tem
  processo de "认证" (certification) que aprova bio via documento (diploma, offer letter,
  etc.). Bio "verified" ganha weight.
- **VPN não é canal legítimo** — operar via interface oficial.
- **Censura ativa** — political, health medical claims sem license, financial advice
  regulated. Zhihu tem revisão + community reporting. Answer censurado + downvote =
  account score down.
- **Advertising labels** — brand answer precisa label "商业推广"; brand-column posts
  pagos precisam sinalizar. Detected non-disclosure = penalty.
- **Answer manipulation** — comprar upvote / follow em batch = ban. Zhihu tem alto skill
  em detectar bot behavior.
- **Segredos** (Zhihu API/OAuth) via Infisical.

## Fluxo padrão da skill (resumo)

1. **Diagnóstico** — vertical de high-consideration B2B/tech/edu/health/finance? Se sim,
   Zhihu é útil. Se produto low-consideration FMCG, Zhihu é secundário.
2. **Perfil** — individual specialist (não brand puro).
3. **Question pipeline** — scan semanal + scorecard de impacto.
4. **Content calendar** — 2-4 answers + 1 column + 1-2 Live/mês.
5. **Answer canônico** — TLDR + credentials + 3-7 seções + data + counter-take + closing.
6. **Community engagement** — comment + cross-link + colaboração no vertical.
7. **Long-game** — 6-12 meses para authority; não expectar viral rápido.
8. **KPI mensal** — upvote total, save rate, follower growth, keyword ranking em Baidu
   (indireto), inbound qualified (via WeChat OA linkado).

## Checklist da skill
- [ ] Perfil individual (não brand puro) certificado
- [ ] Scorecard de impacto aplicado antes de cada answer
- [ ] Answer canônico com TLDR + credentials + estrutura clara
- [ ] Columns editoriais em série (não avulso)
- [ ] Zhihu Live + Roundtable considerado quando escala
- [ ] Community engagement (comment + cross-link) contínuo
- [ ] Compliance (política, health, financial claims revisados)
- [ ] Segredos no Infisical
- [ ] Publicação via interface oficial
- [ ] KPI mensal + tracking indireto Baidu SEO
