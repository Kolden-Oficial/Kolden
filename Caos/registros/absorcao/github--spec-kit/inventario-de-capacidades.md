# F3 — Inventário de capacidades — github--spec-kit

- **slug:** github--spec-kit · **sha:** b7e67f55 · **rota:** A
- **natureza:** framework/metodologia de **Spec-Driven Development (SDD)** — fluxo `Constitution → Specify → Clarify → Plan → Tasks → Analyze → Implement` com comandos-slash agnósticos de agente, templates, extensões, presets, workflows e um CLI instalador multi-agente.
- O coração absorvível são os **10 comandos-método** (`templates/commands/*.md`) + os **5 templates** de artefato. O CLI (`src/specify_cli`) e o sistema de integrações são camada-vendor.
