### Absorção de Repositório / Anti-perda (protocolo-de-absorcao-sem-perda)

Wrapper `.sh` deve DETECTAR o interpretador com probe `for c in python3 python py; do command -v "$c" && "$c" -c "import sys" && PY=$c`; o probe filtra o stub porque ele sai != 0 com args | 2026-06-24
- Path lido por reflexo (hook) deve ancorar em `$CLAUDE_PROJECT_DIR`, nunca relativo ao CWD — o hook não garante o diretório de trabalho. O protocolo original usava `pathlib.Path("registros/...")` relativo; corrigido para `Path(os.environ["CLAUDE_PROJECT_DIR"])/...` com fallback CWD | 2026-06-24
