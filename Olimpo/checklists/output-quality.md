# Checklist de Qualidade de Saída de Estratégia Executiva

**ID do Checklist:** CLEVEL-CL-001
**Referenciado por:** tasks/review.md
**Propósito:** Validar entregáveis de estratégia executiva quanto à qualidade antes da entrega ao usuário.

[[LLM: INSTRUÇÕES DE INICIALIZAÇÃO

Este checklist valida especificamente a saída de estratégia executiva.

ABORDAGEM DE EXECUÇÃO:
1. Para cada categoria, verifique cada item em relação ao entregável
2. Marque os itens como [x] Aprovado, [ ] Reprovado, [N/A] Não Aplicável
3. Itens CRÍTICOS bloqueiam a entrega; itens não críticos são consultivos

## 1. Alinhamento Estratégico

- [ ] A estratégia se alinha à missão, à visão e aos objetivos de longo prazo da empresa (CRÍTICO)
- [ ] O posicionamento competitivo é abordado — onde competimos e como vencemos? (CRÍTICO)
- [ ] As dinâmicas de mercado e as tendências do setor são consideradas
- [ ] A estratégia se apoia nas forças existentes em vez de ignorá-las
- [ ] Os trade-offs estratégicos são explícitos — o que estamos escolhendo NÃO fazer?

## 2. Implicações Financeiras

- [ ] O impacto na receita é quantificado ou estimado com as premissas declaradas (CRÍTICO)
- [ ] A estrutura de custos é abordada: investimento necessário, custos contínuos, ponto de equilíbrio
- [ ] O ROI ou o período de payback é calculado quando aplicável
- [ ] As implicações de fluxo de caixa são consideradas, não apenas o DRE
- [ ] Modelagem de cenários: melhor caso, caso base, pior caso com resultados financeiros

## 3. Avaliação de Risco

- [ ] Os riscos principais são identificados nas dimensões: mercado, operacional, financeiro, regulatório (CRÍTICO)
- [ ] Cada risco tem avaliação de probabilidade e impacto
- [ ] Estratégias de mitigação ou planos de contingência são definidos
- [ ] Cenários de resposta competitiva são considerados
- [ ] Dependências e pontos únicos de falha são identificados

## 4. Viabilidade de Execução

- [ ] O cronograma é realista com marcos em fases (CRÍTICO)
- [ ] Os requisitos de recursos são especificados: pessoas, orçamento, tecnologia, parcerias
- [ ] A lacuna de capacidades organizacionais é avaliada: temos o que precisamos?
- [ ] As considerações de gestão de mudanças são abordadas
- [ ] Vitórias rápidas são identificadas para construir momentum junto com as apostas de longo prazo

## 5. Governança e Responsabilização

- [ ] Os direitos de decisão são claros: quem aprova, quem executa, quem é consultado (CRÍTICO)
- [ ] KPIs e métricas de sucesso são definidos com metas
- [ ] A cadência de revisão é estabelecida: quando verificamos o progresso?
- [ ] Os caminhos de escalonamento para bloqueios são definidos
- [ ] Estrutura de responsabilização: donos nomeados para cada frente de trabalho

## 6. Comunicação e Stakeholders

- [ ] O impacto nos stakeholders é mapeado em toda a organização
- [ ] A narrativa para conselho/investidores é considerada quando relevante
- [ ] O plano de comunicação interna está delineado
- [ ] As implicações voltadas ao cliente são abordadas
- [ ] O sumário executivo é conciso e pronto para decisão

## Critérios de APROVAÇÃO/REPROVAÇÃO

**APROVADO:** Todos os itens CRÍTICOS [x] e menos de 3 reprovações não críticas.
**REVISAR:** Todos os itens CRÍTICOS [x] mas 3+ reprovações não críticas.
**REPROVADO:** Qualquer item CRÍTICO não marcado.
