# Motor combinatorio + anti-slop + disciplina

> Detalhamento operacional do motor de variacao usado pelo SKILL.md.
> Consultar quando for compor uma nova direcao de referencia; nao decorar.

## Motor combinatorio (escolher UMA opcao por categoria)

Executar consistentemente. NAO misturar tudo em caos.

### Theme paradigm
1. Pristine Light Mode — off-white/cream/paper, dark text
2. Deep Dark Mode — charcoal/graphite/zinc, glow so se justificado
3. Bold Studio Solid — campos de cor controlados (oxblood, royal blue, forest, vermilion, emerald)
4. Quiet Premium Neutral — bone, sand, taupe, stone, smoke

### Background character
1. Grid tecnico sutil / dotted field
2. Solid puro com gradient ambient sutil
3. Full-bleed cinematic com contrast control
4. Paper/material tactile

### Typography character
1. Satoshi-like grotesk clean
2. Neue Montreal-like refined grotesk
3. Cabinet/Clash-like expressive display
4. Monument-like compressed statement
5. Serif editorial + sans pairing
6. Swiss rational sans com forte hierarquia

Nunca cair em "default web typography energy" — Inter chapado, sem escala.

### Hero architecture
1. Cinematic Centered Minimalist
2. Asymmetric Split Hero
3. Floating Polaroid Scatter
4. Inline Typography Behemoth
5. Editorial Offset Composition
6. Massive Image-First Hero com texto restrito

### Section system
1. Modular bento rhythm estrito
2. Alternating editorial blocks
3. Poster-like stacked storytelling
4. Gallery-led visual cadence
5. Swiss grid discipline
6. Asymmetric premium marketing flow

### Signature components (escolher 4)
- Diagonal Staggered Square Masonry
- 3D Cascading Card Deck
- Hover-Accordion Slice Layout
- Pristine Gapless Bento Grid

### Motion-implied language (escolher 2)

## Composition anchor (por secao)

O classico **left-text / right-image** e o mais overused do universo IA.
**Permitido, mas nao default.** Cada secao escolhe 1 anchor; no site
inteiro tem que aparecer no minimo 3 anchors diferentes.

- Centered statement
- Top-left lead, support bottom-right
- Bottom-left text over background image
- Bottom-right CTA cluster
- Left-third caption + right-two-thirds visual (raro)
- Right-third caption + left-two-thirds visual (inverted classic)
- Centered low (texto na parte de baixo sobre imagem)
- Off-grid editorial offset
- Stacked center (label / headline / sub / CTA todos centrados, ultra minimal)
- Image-as-canvas com texto overlaid em safe area

## Background mode (por secao)

Escolher 1 por secao. Variar atraves da pagina.

- Solid + inline asset
- Textura/paper/grid como background
- Full-bleed image background com overlay tonal (texto muito legivel)
- Editorial side-image (50/50, 60/40, 40/60, invertible)
- Image-as-canvas + texto overlaid em safe area
- Flat color block + product crop pequeno
- Cinematic tonal gradient (palette-matched, low chroma)
- Atmospheric photo com strong color grade
- Duotone treated image (palette-locked)
- Soft radial vignette + product crop
- Micro-noise gradient sobre solid
- Color-blocked diptych (dois flat fields se encontrando)

## CTA variation

- Classic primary pill
- Outline / ghost
- Underlined inline link com arrow
- Banner-style full-width
- Oversized headline + tiny CTA hint
- CTA como caption sob visual forte

No site inteiro, variar CTA no minimo uma vez. A acao primaria fica
inconfundivel.

## Hero scale (pagina inteira, escolher 1)

- **Giant Statement** — tipo massivo, imagem grande, domina o primeiro viewport
- **Mid Editorial** — balanced tipo/imagem, cinematic mas nao tela-inteira
- **Mini Minimalist** — logo pequeno + statement curto + CTA fino, quase sem imagem (confidence restraint, NAO fraqueza)

## Narrative / concept spine (escolher 1)

Propagar atraves dos visuais e da copy curta:
- Artifact / collectible
- Journey / pilgrimage
- Tool / precision instrument
- Living system / garden
- Stage / spotlight
- Archive / dossier

## Second-read moment (escolher exatamente 1)

Momento nao-obvio mas legivel, colocado uma vez na pagina:
- Asymmetric bleed que ainda respeita hierarquia
- Uma pontuacao ou numeral oversized servindo estrutura
- Uma troca de material inesperada (paper vs gloss vs metal)
- Um side-rail vertical de nota editorial
- Um macro crop carregando brand color naturalmente

Evitar gimmick-por-gimmick — o momento serve o scan order ou o brand
recall.

## Anti-AI-slop rules

### Layout slop
- Endless centered sections
- Rows identicos de cards secao apos secao
- Blocos clonados left-text/right-image
- Simetria perfeita mas sem vida
- Complexidade fake sem hierarquia
- Decoracao vazia sem proposito

### Visual slop
- Gradientes purple/blue AI default
- Muitas glowing edges
- Blobs/spheres flutuando aleatoriamente
- Glassmorphism empilhado sem razao
- Detalhes futuristas random sem estrutura
- Ruido over-rendered que esconde o layout

### Typography slop
- Heading gigante + subcopy fraca minuscula
- Muitos font moods na mesma pagina
- Line breaks awkward
- Caps preguicoso em tudo
- Gradient headline como atalho de "premium"

### Content slop
Verbos banidos: unleash, elevate, revolutionize, next-gen, seamless,
powerful solution, transformative platform.

Nomes de marca fake banidos: Acme, Nexus, Flowbit, Quantumly, NovaCore.

### Density slop
- Secoes over-packed
- Card overload em cada bloco
- Spacing minusculo entre grandes secoes
- Tentar preencher cada area vazia

### Carousel / marquee slop
- Logo strips infinitos repetindo os mesmos 6 blobs
- "Trusted by" ticker de logos ilegiveis
- Auto-play dots no hero sem proposito semantico

### Data / KPI slop
- Tres colunas identicas de stat ("99% satisfaction", "$10 saved", "infinity scale") se o usuario nao pediu KPIs
- Dashboards fake com charts sem sentido shading o layout real

## Disciplina de cor e material

**Palette discipline (site inteiro):**
- 1 primary (brand anchor)
- 1 secondary (supporting tone)
- 1 accent (sparingly para CTA / highlight)
- Neutral scale (background, surface, text, hairline)

Section-level mood shifts reusam a mesma paleta — sem full theme swap
por secao.

**Background-image harmony:**
- Imagem tem que tonalmente match a palette (nao brigar)
- Overlays (dark, light ou color tint) mantem o texto legivel
- Brand accent permanece consistente independente do background

**Gradient discipline:**

Permitido e encorajado (usar com confianca):
- Low-chroma palette-matched tonal gradients (ink-graphite, cream-sand, ivory-warm grey)
- Single-hue atmospheric grades atras de hero photography
- Soft vignettes e radial depth guiando o olho
- Noise-textured gradients adicionando tactile depth sem color noise
- Editorial color washes matching brand mood

Banidos (AI gradient slop):
- Rainbow / mesh blob gradients
- Purple-to-blue "AI" defaults
- Pink-to-orange "creator" defaults
- Neon edges e glow halos sem proposito
- Gradient text como atalho de premium
- Gradients competing com imagery em vez de suportar

**Background confidence rule:** nao retornar white surface plano por
default. Quando o brief, brand mood ou job da secao pede atmosfera, usar:
full-bleed image, duotone/graded photo, tonal gradient, tactile material,
ou confident flat color field — escolhido de proposito.

## Continuity rule (site inteiro)

Atraves das imagens per-section, enforcar UM brand world:
- Mesma paleta e accent logic
- Mesma familia tipografica e escala
- Mesma familia de CTA (variacoes de estilo OK, identidade nao)
- Mesma linguagem de border radius
- Mesmo tratamento de imagem (grade, materials, framing)
- Mesmo tom nas short copy

Um visitante scrollando atraves de todos os frames tem que ler como um
unico site.

## Section rhythm

Uma high-end site nao e caixas repetidas. Variar:
- Densidade
- Ratio image-to-text
- Alignment
- Escala
- Whitespace
- Card grouping
- Intensidade de background
- Tempo visual

Regras:
- Rhythm variation nao quebra cleanliness geral
- Manter pagina balanceada de topo a base
- Section heights podem variar; spacing entre secoes fica controlado
- Evitar salto abrupto entre secao pequena e gigante sem breathing room
- Pagina inteira: curada, smooth, consistente

## Extra creativity & implementation edge

### Cross-section contrast
Variar deliberadamente foreground/background intensity no minimo duas
vezes (lighter -> richer -> calmer) — o scroll fica pacing.

### CTA specificity
Uma acao primaria inconfundivel por viewport tier; secundarias parecem
secundarias (scale, outline, ghost).

### Image variety
Minimo dois image crops distintos no site — macro product + contextual
environment, ou portrait editorial + widescreen artifact. Nada de uma
silhueta stock repetida.

### Data-viz restraint
Charts so quando o site logicamente pede (analytics, pricing, infra,
observability). Senao prova humana: quotes, receipts, timelines,
screenshots de workflow real.

### Cultural / tonal alignment
Quando o brief nomeia industria ou regiao, orientar paleta e temperamento
tipografico. Nao entregar "neutral SF startup" default.

### Mobile-implied fidelity
Mesmo em mocks desktop, manter tap-friendly hit sizes e caption sizes
legiveis; stacking order implica narrativa single-column sa.

### Conversion focus
Cada secao tem um trabalho. Mesmo design artistico tem que ler como site
real:
- Hero comunica valor em segundos + oferece uma next action obvia
- Proof (logos, quotes, metrics) parece earned, nao stuffed
- Pricing ou CTA sections parecem decisivas, nao enterradas
- Ultima secao fecha: um CTA forte + trust cue

### Composition variety check
Logar internamente o anchor + background mode. REJEITAR o set se:
- Mesmo composition anchor repete mais de 2 secoes em sequencia
- Mesmo background mode repete mais de 3 secoes em sequencia
- Toda secao e inline-asset (sem full-bleed nunca) E o brief NAO pede minimalismo/typography-only/swiss/ultra simple

Para briefs nao-minimalistas: forcar no minimo um full-bleed (ou
duotone/atmospheric) background e no minimo uma secao mini-minimalist em
qualquer multi-section site.

Para briefs minimalistas: regra suspensa. Restraint E o design.

## Clarity check completo

1. Hierarquia obvia?
2. Hero clean o suficiente?
3. Design visualmente distinctive?
4. Livre de AI tells obvios?
5. Premium em vez de template-like?
6. Alguem consegue codar a partir disso?
7. Multiplas imagens claramente pertencem juntas?
8. Imagery usada com forca (variacao, nao crop repetido)?
9. Pagina respira? Nao e densa demais?
10. Spacing suficiente entre secoes?
11. Criatividade intencional e premium (concept spine visivel)?
12. Spacing entre secoes even e controlado?
13. Secoes menores ainda com espaco em volta para parecer clean?
14. Exatamente UM "second-read moment" disciplinado?
15. Composicao variada atraves das secoes?
16. Hero scale (giant/mid/mini) escolhido e executado cleanly?
17. Path de conversao claro (hook -> proof -> action)?
18. Palette consistente atraves de todas as imagens?
19. Cada imagem horizontal (web) / vertical (mobile) e uma-secao-somente?
20. Total de imagens = numero de secoes (nunca menos)?
21. Hero em composicao variada (nao caiu no default text-left/image-right)?
